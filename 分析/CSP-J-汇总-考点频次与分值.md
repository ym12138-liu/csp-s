## 4. 7 年命题趋势观察

1. **算法稳坐 60%+ 分值**：阅读程序 + 完善程序合计 70 分，几乎全部围绕算法。
2. **二叉树 / 排列组合 = 单选必考双柱**：**7 年 7 中**，完全没有缺席。
3. **DP 难度逐年加深，并在 2025 达到顶峰**：
   - 2022 阅读 2 鸡蛋掉落（递归 → DP 对照）
   - 2023 完善 2 编辑距离（**首个二维 DP 完善程序**）
   - 2024 阅读 2 爬楼梯最小代价（一维 DP）
   - 2025 阅读 2 + 阅读 3（**一卷出现 2 段 DP**：双指针 1D DP + LCS 2D DP）
4. **完善程序 = 模板背诵考场**：
   - 二分查找（21、23、24）
   - 计数排序 / 试根 / 因数枚举（19、20、22、24）
   - BFS Flood Fill（22）
   - 编辑距离 DP（23）
   - 汉诺塔（24）
   - **RLE 字符串解码 + Boyer-Moore 摩尔投票（25 新增）**
5. **位运算稳定为拉分点**：21（lowbit/popcount）、22（Morton）、25（`x&(x-1)`）。
6. **2024–2025 单选侧重 C++ 语法**：const/union/类型/循环/string/引用 — 强调对 C++ 基础语法的扎实掌握。
7. **数学题分布稳定但形式多变**：从隔板（19/20）→ 容斥（24/25）→ 鸽巢（19）→ 路径计数（25）轮换。
8. **2025 新趋势：经典算法思想题进入完善程序** — 摩尔投票"抵消"思想需要的不是模板而是理解。
