## 四、本年度考点频次小结

| 知识一级 | 题数/段 | 估算分值 |
|---|---|---|
| 计算机基础（进制 / 存储 / OS） | 4 题 | 8 |
| 程序语言（const / union） | 2 题 | 4 |
| 数据结构（链表 / 三叉树 / 表达式 / 二叉树 / 拓扑） | 5 题 | ≈ 10 |
| 算法（哈夫曼 / 高精度 / DP / 二分 / 因数） | 2 题 + 阅读 1+2+3 + 完善 1+2 | ≈ 70 |
| 数学（组合 / 几何） | 2 题 + 阅读 1 部分 | ≈ 8 |

**命题特点：**
- **二维 DP**（编辑距离）首次进入完善程序，是 CSP-J 难度的明显抬升。
- 阅读程序 2 用 LCS 解决"判断循环移位"是算法识别的好题。
- 数据结构题覆盖广（链表 / 树 / 表达式 / 拓扑 / 三叉树），是 CSP-J 单选基本盘。
