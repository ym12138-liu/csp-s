# 普及组（CSP-J）转提高组（CSP-S）必学算法

> 本文以 `分析/CSP-S-汇总-考点频次与分值.md` 中 2020–2025 年 CSP-S 初赛逐题考点统计为唯一依据，给出从 CSP-J 跨入 CSP-S 必须补齐的算法 / 数据结构清单、学习路径、典型代码模板与练习建议。
>
> 阅读对象：已稳定拿下 CSP-J 复赛 200+，希望冲击 CSP-S 初赛 70+ / 复赛 200+ 的同学。

---

## 0. 普及组 vs 提高组的本质差距

| 维度 | CSP-J（普及组） | CSP-S（提高组） |
|---|---|---|
| 算法深度 | 模拟 / 贪心 / 简单 DP / 基础搜索 / 排序 | DP 多种范式、图论算法、数据结构、数论 |
| 复杂度要求 | O(n²) 多数可过 | 经常需要 O(n log n) 甚至 O(n √n) |
| 阅读程序 | 不考 | 3 段，平均 13 分/段，需识别模型 |
| 完善程序 | 不考 | 2 段，30 分；多为模板算法 |
| 数学要求 | 进制、简单组合 | 数论（GCD / 逆元）、容斥、组合 |

**核心差距：**
- ➡️ 从"会写"升级到"看代码就能识别经典算法 + 分析复杂度"。
- ➡️ 从"用 STL 暴搜"升级到"会自己造数据结构（堆、并查集、Trie 等）"。
- ➡️ 从"题意拆模拟"升级到"题意 → 抽象成图/DP 状态/数论模型"。

## 2. 详细学习路径（建议 6–8 个月，每周 2–3 模块）

### 阶段 A：复杂度与基础数据结构强化（2 周）

**学习目标：** 看到任意嵌套循环、递归代码，能 30 秒说出 Big-O。

**具体内容：**
1. **主定理**：T(n) = aT(n/b) + f(n) 的三种情况；
2. **手动推**：归并排序、快速幂、KMP、二分查找的复杂度；
3. **数据结构基础**：手写 stack / queue / deque / 链表；理解 STL 的 push_back / push 是均摊 O(1)。
4. **必背**：
   - 二分查找：`O(log n)`
   - 堆排序 / 归并：`O(n log n)`
   - 快排平均：`O(n log n)`，最坏 `O(n²)`
   - DFS/BFS（邻接表）：`O(n + m)`
   - Dijkstra（堆优化）：`O((n + m) log n)`

**练习：** 把 2023 单选 11、2025 单选 11、每年的"复杂度题"全部刷一遍。

---

### 阶段 B：搜索与递归升级（2 周）

**学习目标：** 把 CSP-J 阶段的"暴搜"系统化为 DFS / BFS / 折半 / 双向 / 记忆化。

**重点技能：**

#### B1. DFS 回溯模板
```cpp
void dfs(int dep) {
    if (dep == n + 1) { ans++; return; }
    for (int i = 1; i <= n; ++i) {
        if (vis[i]) continue;
        if (/* 题目约束 */) continue;
        vis[i] = true; p[dep] = i;
        dfs(dep + 1);
        vis[i] = false;       // 必须回溯
    }
}
```
> 对应 CSP-S 2025 阅读 1。

#### B2. BFS 层序模板
```cpp
queue<State> q; q.push(start);
dist[start] = 0;
while (!q.empty()) {
    auto u = q.front(); q.pop();
    for (auto v : adj(u)) {
        if (dist[v] == -1) {
            dist[v] = dist[u] + 1;
            q.push(v);
        }
    }
}
```

#### B3. 折半搜索（Meet in the Middle）
**适用：** 状态空间 2ⁿ 太大，但 2^(n/2) 可接受。
**步骤：**
1. 把所有变量分成左/右两半，各自枚举所有组合（O(2^(n/2))）；
2. 把左半结果排序；
3. 对右半每个结果在左半二分配对。

> 直接对应 CSP-S 2025 阅读 3。

#### B4. 记忆化搜索
```cpp
int f[N][N];
int dfs(int x, int y) {
    if (f[x][y] != -1) return f[x][y];
    // base case
    int res = ...;
    return f[x][y] = res;
}
memset(f, -1, sizeof f);
```

**练习：** P1219 八皇后、P1135 奇怪的电梯（BFS）、P4799 World Tour Finals（MITM）。

### 阶段 C：动态规划全谱系（4 周，最重要）

**核心：** DP 是 CSP-S 提分的最大杠杆，2020–2024 平均每年 25+ 分与 DP 直接相关。

#### C1. 线性 DP（1 周）
- 模板题：最长上升子序列（LIS）、最长公共子序列（LCS）。
- 进阶：LIS 二分优化 O(n log n)。

#### C2. 区间 DP（1 周）
- 模板题：石子合并、回文串相关、矩阵链乘。
- 转移：`f[l][r] = min(f[l][k] + f[k+1][r] + cost)`。

#### C3. 背包 DP（4 天）
- 0-1 背包、完全背包、多重背包（二进制拆分）、分组背包；
- 注意循环顺序：0-1 倒序，完全正序。

```cpp
// 0-1 背包
for (int i = 1; i <= n; ++i)
    for (int j = V; j >= w[i]; --j)
        f[j] = max(f[j], f[j-w[i]] + v[i]);
```

> 对应 CSP-S 2025 单选 9、CSP-S 2020 完善 1（分数背包贪心）。

#### C4. 状压 DP（1 周）
- 何时用：n ≤ 20 左右，状态可压成 bitmask。
- 模板题：旅行商（TSP）、互不侵犯。

```cpp
for (int s = 0; s < (1<<n); ++s)
    for (int i = 0; i < n; ++i)
        if (s >> i & 1)
            f[s][i] = max(f[s ^ (1<<i)][j] + cost[j][i], ...);
```

> 直接对应 CSP-S 2020 完善 2、CSP-S 2024 阅读 2。

#### C5. 计数 DP（4 天）
- DAG 上路径数 / 字典序第 k 小路径（拓扑序逆推）；
- Catalan 数、错排、隔板法。

> 直接对应 CSP-S 2023 完善 1。

### 阶段 D：图论核心算法（3 周）

#### D1. 图的存储（必须双手熟）
- **链式前向星**：CSP-S 完善程序的标配；
- **邻接表 + vector<vector<int>>**：写起来快，但内存常数大。

```cpp
int head[N], nxt[M], to[M], w[M], tot;
void add(int u, int v, int c) {
    nxt[++tot] = head[u]; to[tot] = v; w[tot] = c; head[u] = tot;
}
```

#### D2. 最短路（必考）
- **Dijkstra + 堆优化**：负权边不可用，复杂度 O((n+m) log n)。
- **SPFA**：可处理负权但易被卡，O(km)。
- **Floyd**：多源最短路，O(n³)。
- **拆点 / 分层最短路**：处理"至多 1 次免费"、"次短路"等带状态的最短路。

```cpp
// 分层 Dijkstra（对应 CSP-S 2025 完善 1）
struct State { ll dist; int u, layer; };
priority_queue<State, vector<State>, greater<>> pq;
pq.push({0, s, 0});
d[s][0] = 0;
while (!pq.empty()) {
    auto [dist, u, used] = pq.top(); pq.pop();
    if (dist > d[u][used]) continue;
    for (auto [v, w] : adj[u]) {
        if (d[u][used] + w < d[v][used]) /* 普通转移 */;
        if (used == 0 && d[u][0] < d[v][1]) /* 用免费边 */;
    }
}
```

#### D3. 拓扑排序 + DAG DP
- Kahn 算法：BFS 入度为 0 的点；
- 反向拓扑序常用于 DAG 上从终点向前 DP。

> 直接对应 CSP-S 2023 完善 1。

#### D4. 最小生成树
- **Kruskal**：排序边 + 并查集，O(m log m)。
- **Prim**：稠密图友好，O(n²)。

> 对应 CSP-S 2025 单选 7。

#### D5. LCA
- 倍增 LCA：O(n log n) 预处理，O(log n) 查询；
- Tarjan 离线 LCA：O((n+q) α(n))；
- Euler 序 + ST 表：O(n log n) 预处理，O(1) 查询（2021 完善 2 进阶版）。

### 阶段 F：字符串算法（2 周）

#### F1. KMP
- next 数组（也叫 fail 数组、失配函数）；
- 必背：next[i] = "P[0..i] 的最长公共前后缀长度"。

```cpp
void getNext(const string& p) {
    next_arr[0] = 0;
    for (int i = 1, k = 0; i < p.size(); ++i) {
        while (k && p[k] != p[i]) k = next_arr[k - 1];
        if (p[k] == p[i]) ++k;
        next_arr[i] = k;
    }
}
```

> 对应 CSP-S 2025 单选 2。

#### F2. 字符串 Hash
- 单 Hash / 双 Hash；
- 用于：判等、最长公共前缀、子串去重。

> 对应 CSP-S 2024 阅读 3。

#### F3. Trie：见 E6。

#### F4. Sunday / BM（了解即可）
> 对应 CSP-S 2022 阅读 1。

### 阶段 G：数学（2 周）

#### G1. 组合计数
- 排列 P(n, k)、组合 C(n, k)；
- 隔板法、错排、Catalan、Stirling；
- Lucas 定理（求 C(n,k) mod p）。

> 对应 CSP-S 2025 单选 1、2024 单选 4。

#### G2. 容斥原理
- 经典："1~N 中不被 a, b, c 整除的数"；
- 集合大小 / 排列数推导。

> 对应 CSP-S 2025 单选 13。

#### G3. 数论
- GCD / exGCD；
- 模逆元（费马小定理 / exGCD 两种实现）；
- 快速幂；
- 欧拉函数 + 欧拉筛法；
- 中国剩余定理（CRT，了解）。

```cpp
ll qpow(ll a, ll b, ll p) {
    ll r = 1 % p;
    for (; b; b >>= 1, a = a * a % p)
        if (b & 1) r = r * a % p;
    return r;
}
ll inv(ll a, ll p) { return qpow(a, p - 2, p); } // p 为质数
```

> 对应 CSP-S 2024 单选 9、2023 阅读 2（欧拉函数）。

## 4. 常见误区与避坑

| 误区 | 真相 |
|---|---|
| "我会写 DFS 就够了" | CSP-S 阅读程序常考 BFS/双向 BFS/MITM/记忆化搜索的**辨识** |
| "STL 太慢，必须手写" | 本质上 `priority_queue` / `set` / `map` 在初赛和绝大多数 NOIP 题已经够用 |
| "图论只学 Dijkstra 就行" | 拓扑排序、最小生成树、LCA、强连通分量都进入了近 3 年初赛 |
| "数学不重要" | 2023、2024 数学题占比飙升至 12 分以上 |
| "状压 DP 太难，跳过" | 2020、2024 状压 DP 直接 12+ 分，绕不过去 |
| "完善程序靠蒙" | 完善程序逻辑链很强，前后空答案有强约束，蒙对率仅 25% |
