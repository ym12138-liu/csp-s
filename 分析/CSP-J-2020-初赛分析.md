## 四、本年度考点频次小结

| 知识一级 | 题数/段 | 估算分值 |
|---|---|---|
| 计算机基础（地址 / 编译器 / 进制 / 存储） | 4 题 | 8 |
| 程序语言（逻辑运算） | 1 题 | 2 |
| 数据结构（链表 / 图 / 栈 / 二叉树） | 4 题 | 8 |
| 算法（冒泡 / 递归 / 字符映射 / 进制 / DFS / 试除 / 贪心） | 2 题 + 阅读 1+2+3 + 完善 1+2 | ≈ 70 |
| 数学（排列组合 / 同余 / 隔板） | 4 题 | 8 |

**命题特点：**
- 数学题占比依然大（4/15 单选，含隔板法、捆绑法、同余）。
- 阅读 3 是 DFS 回溯题，难度对 CSP-J 而言挑战较大。
- 完善程序 2 区间贪心是 CSP-J 罕见的"贪心模板题"，提示选手要熟练区间问题。
