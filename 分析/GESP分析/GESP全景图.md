# GESP C++ 1-8 级全景图

> 把 GESP 一级到八级看成一张图：每一级在哪里、跨过去要补什么、整条路要走多久。

## 0. GESP 是什么

| 项目 | 内容 |
|---|---|
| 全称 | CCF GESP（Grade Examination of Software Programming）非专业级软件能力认证 |
| 主办 | 中国计算机学会（CCF），与 CSP-J/S 同主办方 |
| 等级 | 1–8 级，逐级递进 |
| 卷面 | 单选 15×2 + 判断 10×2 + 编程 2×25 = **100 分** |
| 时间 | 90 分钟 |
| 过关 | 60 分 |
| 频次 | 每年 3 月 / 6 月 / 9 月 / 12 月共 4 次 |
| 用途 | 衡量编程能力 · 部分省份信奥圈做基础筛选 |

## 1. 8 级难度梯队（一行看懂）

| 级别 | 一句话定位 | 核心新内容 | 难度对标 |
|---|---|---|---|
| **一级** | C++ 入门巩固 | 表达式 + if/for/while + 简单数学 | 学了 1–2 个月 |
| **二级** | 数组与图形 | 一维数组 + 嵌套循环 + 多条件 | 学了 3–4 个月 |
| **三级** | 进制与位运算 | 进制转换 + 位运算 + 字符串 + 内置函数 | 学了 6 个月 |
| **四级** | 第一道大关 | **指针 + 函数 + 二维数组 + 三种排序** | 入门后期 |
| **五级** | 接近 CSP-J 入门 | **链表 + 高级排序 + 数论 + 贪心** | 提高初级 |
| **六级** | 数据结构核心 | **二叉树 + BST + OOP + DP 入门** | CSP-J 复赛核心 |
| **七级** | 对接 CSP-S 初赛 | **图论 + 哈希 + 高级 DP + 复杂度递推** | CSP-J 复赛 / CSP-S 初赛入门 |
| **八级** | GESP 顶级 | **图论四大算法 + 组合数学 + 树形 DP + 概率** | CSP-S 初赛中等 |

## 2. 难度跨越的"3 个分水岭"

### 第一道分水岭：三 → 四级
**新增：指针 + 函数 + 排序**
从"会写"上升到"懂数据结构"。指针是公认最劝退的考点，许多娃在四级出局。

### 第二道分水岭：五 → 六级
**新增：树 + DP + OOP**
树的递归思想 + DP 状态转移是数据结构课的核心，一旦掌握，CSP-J 复赛同步打开。

### 第三道分水岭：七 → 八级
**新增：四大图算法 + 组合数学**
Kruskal / Prim / Dijkstra / Floyd 一次齐发，组合数学也进入主战场。八级是 GESP 顶峰。

## 3. 全程时间轴（2-3 年规划）

下表假设孩子四年级开始接触 C++、目标六年级 / 初一稳过六-七级。

| 阶段 | 月份 | 目标 |
|---|---|---|
| **启蒙期** | M1-M2 | 学 C++ 基础语法 → 拿一级 |
| **数组期** | M3-M5 | 数组 + 嵌套循环 → 拿二级 |
| **进制期** | M6-M9 | 进制 + 位运算 → 拿三级 |
| **暂停 / 巩固** | M10-M12 | 大量刷题 + CSP-J 入门 |
| **指针关** | M13-M16 | 指针 + 函数 + 三种排序 → 拿四级 |
| **链表数论关** | M17-M20 | 链表 + gcd + 二分 + 贪心 → 拿五级 |
| **树 DP 关** | M21-M28 | 二叉树 + BST + OOP + DP → 拿六级 |
| **图论关** | M29-M36 | 图 + 哈希 + 高级 DP → 拿七级 |
| **顶级冲刺** | M37-M48 | 四大图算法 + 组合 → 拿八级 |

> **实操建议**：1-3 级一般 1-3 个月一过；4-5 级各 3-6 个月；6-8 级各需 6-12 个月。**没必要追求"年内冲八级"** —— 跳级容易底子虚，CSP-S 时反而吃亏。

## 4. 各级试卷结构（统一）

| 题型 | 题量 | 单题分值 | 小计 |
|---|---|---|---|
| 单选题 | 15 | 2 分 | 30 |
| 判断题 | 10 | 2 分 | 20 |
| 编程题 | 2 | 25 分 | 50 |
| **合计** | 27 | — | **100** |

8 级试卷结构相同，**只是知识点深度不同**。这意味着**编程题模板**是穿越 8 级的同一套思路：读输入 → 处理 → 输出。变化的是"处理"那部分用的数据结构 / 算法。

## 8. 升级关键节点的"3 条警示"

### 警示 1 · 不要为了跳级而跳级

许多家长想让孩子半年从五级冲八级。**结果：编程题靠记套路 + 单选丢分，复赛 / NOIP 直接崩**。每升一级前**必须能在该级真题稳定拿 80+**，再考虑下一级。

### 警示 2 · 编程题永远占 50%

GESP 8 级都一样，**编程题占 50 分**。家长容易盯着单选 + 判断刷题，但任何级别**单 / 判 30+ 分 + 编程 1 题 AC = 60 过关**。**编程题的实战训练**比记忆考点更重要。

### 警示 3 · 算法 ≠ 语法

四级开始，**算法主导分值**。即使 C++ 写得很熟，不懂"指针怎么传递""二分怎么写"也照样挂。**算法基础课**（看《算法竞赛入门到进阶》或 OI Wiki）是从四级开始就要常翻的工具书。

## 11. 行动清单（这周可以开始的 3 件事）

1. **定位** · 让孩子限时做一份当前级别下一档的真题，看离过关线（60）差多少。
2. **画图** · 把本文 #10 的全程图打印贴墙上，每过一级打个钩。
