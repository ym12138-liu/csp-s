## 2. 五级 vs 四级 · 关键升级点

| 维度 | 四级 | 五级 |
|---|---|---|
| 数据结构 | 数组 + 结构体 + 指针 | **新增链表（单/双/循环）** |
| 排序 | 三种 O(n²) 排序 | **新增归并 + 快速 O(n log n)** |
| 查找 | 顺序查找 | **新增二分查找 + 二分答案** |
| 算法思想 | 递推 / 简单递归 | **新增贪心 / 分治** |
| 数论 | 不考 | **新增 gcd/lcm、唯一分解、素数筛** |
| 高精度 | 不考 | **新增高精度加减** |
| 编程题 | 排序 + 结构体 | **链表操作 / 二分应用 / 贪心** |

> **结论：** 五级是接近 **CSP-J 复赛入门难度**的级别。

## 5. 编程题考点统计（10 场 × 2 题 = 20 段）

| 题型 | 出现次数 | 难度 | 套路 |
|---|---|---|---|
| 链表操作（插入 / 删除 / 反转） | ≈ 5 / 20 | 中等偏难 | 节点指针操作 |
| 二分答案（切木头 / 跳石头 / 满足条件最大值） | ≈ 5 / 20 | 中等 | 二分 + check 函数 |
| 贪心策略题（任务调度 / 区间覆盖） | ≈ 4 / 20 | 中等 | 排序 + 贪心 |
| 数论应用（gcd / 唯一分解 / 同余） | ≈ 3 / 20 | 中等 | 数学 + 循环 |
| 高精度运算 | ≈ 2 / 20 | 中等 | 数组模拟 |
| 复杂模拟 / 综合应用 | ≈ 1 / 20 | 中等 | 多步骤 |

**编程题升级特征：**
- 数据范围 n ≤ 10⁵-10⁶（部分需要 long long）
- 标准代码长度 30-50 行
- 主要使用：链表 / 二分 / 排序 / 贪心
- 必须会：自定义比较函数 / 二分 check 函数

## 6. 时间轴：10 场命题趋势

| 考期 | 命题特点 |
|---|---|
| 2023.12 | 五级首场 · 链表 + 数论平衡 |
| 2024.03 | 引入二分答案题 |
| 2024.06 | 高精度题首次出现 |
| 2024.09 | 链表题占比上升 |
| 2024.12 | **链表 + 数论 + 二分齐发**（全卷必有） |
| 2025.03 | 贪心题进入主流 |
| 2025.06 | 题量 / 难度抬升明显（卷面 16 页） |
| 2025.09 | 题型趋稳 |
| 2025.12 | **欧几里得 + 唯一分解 + 素数筛**集中考查 |
| 2026.03 | 编程题模板化 |

**整体趋势：**
1. **链表是五级的"门票"** — 不熟练直接丢 30+ 分
2. **数论占比稳定 9-10%** — gcd / 素数筛 / 唯一分解
3. **二分应用深入** — 不只是查找，还有"二分答案"思想
4. **贪心 + 分治概念**进入考点（多以判断题形式）
5. **高精度年年都有 1-2 题**
