### 阶段 B：图论基础（4 周，**核心**）

**核心概念清单**

| 术语 | 含义 |
|---|---|
| 顶点（Vertex / Node） | 图的"点" |
| 边（Edge） | 连接两个顶点 |
| 度数（Degree） | 顶点连接的边数 |
| 无向图 | 边没有方向 |
| 有向图 | 边有方向（起点 → 终点） |
| 完全图 | 任意两点间都有边（边数 = `n(n-1)/2`） |
| 简单图 | 无自环 + 无重边 |
| 连通图 | 任意两点间有路径 |
| 强连通图 | 有向图任意两点互达 |
| 生成树 | 连通图的子图 + 是树（**n-1 条边**） |

**度数定理（必背）：**
- 无向图：所有顶点度数之和 = **边数 × 2**
- 有向图：所有顶点入度和 = 出度和 = **边数**

**模板 1 · 邻接表存图**
```cpp
const int N = 1e5 + 5;
vector<int> adj[N];   // adj[u] 存储 u 的所有邻居

// 加边
adj[u].push_back(v);
adj[v].push_back(u);   // 无向图加双向
```

**模板 2 · 邻接矩阵**
```cpp
int g[N][N];           // g[u][v] = 1 表示 u → v 有边
// 适合稠密图，n ≤ 1000 量级
```

**模板 3 · 图上 BFS**
```cpp
queue<int> q;
bool vis[N] = {false};
q.push(start); vis[start] = true;
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : adj[u]) {
        if (!vis[v]) {
            vis[v] = true;
            q.push(v);
        }
    }
}
```

**模板 4 · 图上 DFS**
```cpp
bool vis[N] = {false};
void dfs(int u) {
    vis[u] = true;
    for (int v : adj[u]) {
        if (!vis[v]) dfs(v);
    }
}
```

**复杂度：**
- 邻接表：BFS / DFS 都是 `O(n + m)`
- 邻接矩阵：BFS / DFS 都是 `O(n²)`

### 阶段 C：哈希表（2 周）

**核心概念**

哈希表 = 用一个**哈希函数** `H(key)` 把 key 映射到数组下标，实现 O(1) 平均查找。

**常见哈希函数：**
```cpp
int H(int x, int p) { return x % p; }   // p 取素数
```

**为什么 p 要选素数？** 因为合数容易让"按某规律的输入"全部撞到同一槽位。

**冲突解决方案：**

1. **开放定址 / 线性探测** — 撞了往后找空位
```cpp
int hash_table[1000];   // 初始化 -1 表示空
int H(int x) { return x % P; }
void insert(int x) {
    int p = H(x);
    while (hash_table[p] != -1) p = (p + 1) % SIZE;
    hash_table[p] = x;
}
```

2. **链地址法** — 每个槽位是一个链表
```cpp
vector<int> hash_table[P];   // 每个槽位是一个 vector
void insert(int x) {
    hash_table[x % P].push_back(x);
}
```

**最坏时间复杂度：** 所有元素映射到同一槽位 → **O(n)**

### 阶段 D：高级 DP（3 周）

**LCS（最长公共子序列）**
```cpp
// dp[i][j] = s1[0..i-1] 和 s2[0..j-1] 的 LCS 长度
int dp[1005][1005];
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        if (s1[i-1] == s2[j-1])
            dp[i][j] = dp[i-1][j-1] + 1;
        else
            dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
    }
}
cout << dp[n][m];
```

**LCS 滚动数组优化（O(n²) 空间 → O(n) 空间）**
```cpp
int dp[2][1005];   // 用两行交替
for (int i = 1; i <= n; i++) {
    int cur = i & 1, prev = !cur;
    for (int j = 1; j <= m; j++) {
        if (s1[i-1] == s2[j-1])
            dp[cur][j] = dp[prev][j-1] + 1;
        else
            dp[cur][j] = max(dp[prev][j], dp[cur][j-1]);
    }
}
```

**完全背包（每个物品可用无限次）**
```cpp
for (int i = 0; i < n; i++)
    for (int j = w[i]; j <= V; j++)   // 注意：正序
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

**0-1 背包 vs 完全背包对比：**
- 0-1 背包：内层**倒序** `for (int j = V; j >= w[i]; j--)`
- 完全背包：内层**正序** `for (int j = w[i]; j <= V; j++)`

### 阶段 E：复杂度递推式（1 周）

**主定理（Master Theorem）简化版**

形如 `T(n) = aT(n/b) + f(n)`，比较 `f(n)` 和 `n^log_b(a)`：

| 关系 | 复杂度 |
|---|---|
| `f(n) < n^log_b(a)` | `T(n) = O(n^log_b(a))` |
| `f(n) = n^log_b(a)` | `T(n) = O(n^log_b(a) · log n)` |
| `f(n) > n^log_b(a)` | `T(n) = O(f(n))` |

**典型例子：**
| 递推 | 解 |
|---|---|
| `T(n) = 2T(n/2) + n` | `O(n log n)`（归并 / 快排） |
| `T(n) = 2T(n/2) + 1` | `O(n)` |
| `T(n) = T(n/2) + 1` | `O(log n)`（二分） |
| `T(n) = T(n-1) + n` | `O(n²)`（递推累加） |
| `T(n) = T(n-1) + T(n-2)` | `O(2ⁿ)`（朴素 Fib） |

### 阶段 F：强连通分量 / 生成树（1.5 周）

**生成树性质（必背）：**
- n 顶点连通图 → 生成树 = **n-1 条边**
- **任意一棵**生成树都满足这个性质（不只是最小的）

**强连通图性质：**
- 有向图的"任意两点互相可达"
- 强连通分量 = 有向图中"互相可达"的最大顶点集合

**Kruskal 求最小生成树（思想）：**
1. 把所有边按权值升序排列
2. 用并查集逐条加边，**避免成环**
3. 加 n-1 条边后停止

### 阶段 G：Flood Fill 泛洪（半周）

**经典模板（既可 BFS 也可 DFS）**
```cpp
int n, m;
char g[1005][1005];
bool vis[1005][1005];
int dx[4] = {0, 0, 1, -1}, dy[4] = {1, -1, 0, 0};

void dfs(int x, int y, char c) {
    vis[x][y] = true;
    for (int d = 0; d < 4; d++) {
        int nx = x + dx[d], ny = y + dy[d];
        if (nx<0 || nx>=n || ny<0 || ny>=m) continue;
        if (vis[nx][ny] || g[nx][ny] != c) continue;
        dfs(nx, ny, c);
    }
}
```

### 套路 2 · LCS 编程题
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string a, b; cin >> a >> b;
    int n = a.size(), m = b.size();
    vector<vector<int>> dp(n+1, vector<int>(m+1, 0));
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            if (a[i-1] == b[j-1]) dp[i][j] = dp[i-1][j-1] + 1;
            else dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        }
    cout << dp[n][m];
    return 0;
}
```

### 套路 3 · BFS 求最短路（无权图）
```cpp
queue<int> q;
vector<int> dist(n+1, -1);
q.push(start); dist[start] = 0;
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : adj[u]) {
        if (dist[v] == -1) {
            dist[v] = dist[u] + 1;
            q.push(v);
        }
    }
}
```

q.push(s); vis[s] = true;
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : adj[u]) if (!vis[v]) { vis[v]=1; q.push(v); }

// 2. 邻接表 + DFS
void dfs(int u) {
    vis[u] = true;
    for (int v : adj[u]) if (!vis[v]) dfs(v);

// 3. 哈希表（链地址法）
vector<int> ht[P];
void insert(int x) { ht[x % P].push_back(x); }
bool find_x(int x) {
    for (int v : ht[x % P]) if (v == x) return true;
    return false;
}

// 4. LCS
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        dp[i][j] = (a[i-1]==b[j-1])
            ? dp[i-1][j-1] + 1
            : max(dp[i-1][j], dp[i][j-1]);

// 5. 完全背包
for (int i = 0; i < n; i++)
    for (int j = w[i]; j <= V; j++)

// 6. Flood Fill（4 联通）
int dx[4]={0,0,1,-1}, dy[4]={1,-1,0,0};
void dfs(int x, int y) {
    vis[x][y] = true;
    for (int d = 0; d < 4; d++) {
        int nx = x+dx[d], ny = y+dy[d];
        if (/* 越界判断 */) continue;
        if (vis[nx][ny] || /* 颜色不匹配 */) continue;
        dfs(nx, ny);
    }
}

## 6. 常见误区 & 提醒

| 误区 | 真相 |
|---|---|
| "图论看代码就懂" | 必须**亲手画图 + 跑算法** 5 遍才稳 |
| "邻接矩阵和邻接表随便选" | 稠密图用矩阵 / 稀疏图用表 · 复杂度差很多 |
| "哈希函数 p 取多少都行" | **必须选素数**，否则规律输入全冲突 |
| "DP 写出来就对" | LCS 边界 `dp[0][?]=0` 易漏，**必须验证** |
| "0-1 背包 vs 完全背包顺序无所谓" | **倒序 = 0-1，正序 = 完全**，不能换 |
| "图论就考 BFS / DFS" | 强连通 / 生成树 / 度数定理也是高频 |
