# GESP 与 CSP 关系图

> 把 GESP 8 级和 CSP-J / CSP-S / NOIP 摆到一条难度坐标上，
> 给家长一份"我家娃下一步该走哪条线"的决策手册。

> 配套文档：本目录下 `GESP全景图.md`（GESP 内部 1-8 级路线）
> 与 `分析/CSP-J-汇总-考点频次与分值.md`、`分析/CSP-S-汇总-考点频次与分值.md`。

---

## 0. 两套体系的定位差异（一段话讲清）

| 维度 | GESP | CSP-J / CSP-S |
|---|---|---|
| 主办 | CCF | CCF |
| 性质 | **能力认证** · 渐进 8 级 | **赛事**（信息学奥林匹克入口） |
| 主要意义 | 学习激励 · 培训机构常用做评估 | 进 NOIP / 省队 · 部分高校自主招生认 |
| 题型 | 单选 + 判断 + 编程（统一 100 分） | 单选 + 阅读程序 + 完善程序（初赛）+ 上机赛（复赛） |
| 频次 | 每年 4 次 | 每年 1 次（9 月初赛 + 10 月复赛） |
| 与升学 | **基本不挂钩升学** | NOIP / 省队成绩**部分省份认可** |

**核心结论**：GESP 是**台阶式技能认证**，CSP 是**真正的赛场**。

## 1. 难度对应表（速查）

| GESP 级别 | 对应 CSP 阶段 | 知识体系命中率 |
|---|---|---|
| 一级 | < CSP-J 入门 | 仅 C++ 入门 |
| 二级 | < CSP-J 入门 | 数组 + 简单算法 |
| 三级 | ≈ CSP-J 入门初赛 单选水平 | 进制 + 位运算 + 字符串 |
| 四级 | ≈ CSP-J 复赛"基础题" | 指针 + 函数 + 排序 |
| 五级 | ≈ CSP-J 复赛"较强" / **≈ CSP-J 拿省二** | 链表 + 数论 + 二分 |
| **六级** | **≈ CSP-J 复赛冲省一** / CSP-S 初赛 60 | 二叉树 + DP + OOP |
| **七级** | **≈ CSP-S 初赛 60+** / CSP-J 复赛 250+ | 图论 + 哈希 + 高级 DP |
| **八级** | **≈ CSP-S 初赛 70+ / 拿奖** | 四大图算法 + 组合数学 |

> **判读：** GESP 五级前几乎不与 CSP 直接对接；六级开始大幅重叠；八级毕业 = CSP-S 真正的"入场券"。

## 2. 知识点重叠矩阵

下面是 CSP-J 复赛常考点 / CSP-S 初赛高频考点，看 GESP 哪一级开始覆盖：

### 2.1 CSP-J 复赛核心考点 → GESP 对应级别

| CSP-J 考点 | 首次在 GESP 出现 | 备注 |
|---|---|---|
| 一维数组遍历 | 二级 | 编程题主战场 |
| 字符串处理 | 三级 | strcmp / 字符遍历 |
| 三种排序 | 四级 | 冒泡 / 选择 / 插入 |
| 结构体 + 自定义函数 | 四级 | 形参实参 |
| 链表（增删查） | 五级 | 单 / 双 / 循环 |
| 二分查找 + 二分答案 | 五级 | 编程题热门 |
| 数论 gcd / 素数筛 | 五级 | gcd / 埃氏 / 欧拉筛 |
| **0-1 背包 / 简单 DP** | **六级** | CSP-J 复赛必考 |
| **二叉树 + BST** | **六级** | CSP-J 复赛必考 |
| 哈夫曼 + DFS / BFS | 六级 | |

> **结论：** **GESP 六级毕业** ≈ CSP-J 复赛核心考点全覆盖。

### 2.2 CSP-S 初赛高频考点 → GESP 对应级别

| CSP-S 考点 | 首次在 GESP 出现 | 备注 |
|---|---|---|
| 复杂度分析（含主定理） | 七级 | 必考 |
| 二叉树深化（完全 / 满 / 叶子） | 七级 | |
| 图论 BFS / DFS | 七级 | |
| 哈希表 + 冲突 | 七级 | |
| LCS + 滚动数组 | 七级 | |
| **Dijkstra / Kruskal / Prim / Floyd** | **八级** | CSP-S 完善程序必考 |
| **组合数学 + 二项式** | **八级** | CSP-S 数学题主流 |
| **树形 DP / 区间 DP** | **八级** | |
| 排列组合 / 容斥 | 八级 | CSP-S 必考 |
| **Trie / 线段树 / 单调队列** | **超出 GESP** | CSP-S 必须额外补 |
| **状压 DP / 状态压缩** | **超出 GESP** | CSP-S 完善程序常考 |
| **KMP / 字符串 Hash** | **超出 GESP** | CSP-S 阅读程序常考 |

> **结论：** **GESP 八级毕业**对应 CSP-S 初赛**约 60-70%** 覆盖率。剩下的 30-40%（线段树 / 状压 DP / KMP 等）需要在八级毕业后**单独补**。

## 3. 时间投入对比

| 路线 | 总时间 | 结果 |
|---|---|---|
| GESP 1-6 级 | 12-18 个月 | CSP-J 复赛入门 |
| GESP 1-7 级 | 24-30 个月 | CSP-S 初赛 60+ |
| GESP 1-8 级 | 36-48 个月 | CSP-S 初赛 70+ |
| **CSP-S 初赛 70+ 直走** | 24-36 个月 | 跳过 GESP 1-3 级 |
| **CSP-J 拿省一 + CSP-S 70+** | 30-42 个月 | 主流路线 |

**结论：** 想走 OI 路线的话，**GESP 不是必经路径**。但用 GESP 当**阶段性测评**很有价值。

## 4. 4 种典型路径推荐

### 路径 A · "GESP 全程派"（小学起步，节奏舒缓）
**适合：** 小学 3-5 年级，家长想稳扎稳打。
```
小学 3 年级：GESP 一级
小学 4 年级：GESP 二-三级
小学 5 年级：GESP 四-五级
小学 6 年级：GESP 六级 + CSP-J 复赛
初一：GESP 七级 + CSP-S 初赛
初二：GESP 八级 + CSP-S 复赛
初三起：NOIP / 省选
```

### 路径 B · "信奥优先派"（直接走 CSP，省去 GESP 1-3 级）
**适合：** 初一 / 初二开始才接触编程，时间紧。
```
学 C++ 基础（1-3 个月）→ 跳过 GESP 1-3 级
直接刷 CSP-J 真题 → 复赛拿省二
专项补 DP / 图论 / 数据结构 → CSP-S 初赛冲 60+
仍可选考 GESP 5-6-7 级做"过程性认证"
```

### 路径 C · "并行派"（GESP 4-7 + CSP 同步）
**适合：** 五-初一阶段，想要双线认证。
```
GESP 五级 ←同步→ CSP-J 复赛
GESP 六级 ←同步→ CSP-J 复赛省一
GESP 七级 ←同步→ CSP-S 初赛 60+
GESP 八级 ←同步→ CSP-S 初赛 70+
```
> 这是大连许多重点中学 OI 圈实际在走的路线。

### 路径 D · "考级派"（只刷 GESP，不走 CSP）
**适合：** 不打算走信奥升学，把 GESP 当编程能力证书。
```
小学：1-4 级
初中：5-7 级
不参加 CSP / NOIP
```
> 这种路线**不能换升学加分**，但能完成基础 CS 教育。

## 7. 5 个常见误区

| 误区 | 真相 |
|---|---|
| "GESP 八级 = NOIP 拿奖" | **错**。八级只对应 CSP-S 初赛 70 左右，**离 NOIP 拿奖还差 1-2 年专项训练** |
| "不考 GESP 就上不了 CSP" | **错**。CSP 报名**不要求** GESP 任何级别。GESP 是阶段性认证 |
| "GESP 单选满分就稳了" | **错**。50 分单选 + 20 分判断都对 = 70，**编程题必须 1 题 AC** |
| "六级 = CSP-J 国一" | **错**。六级覆盖 CSP-J 复赛核心考点 ≠ 实际竞赛拿奖。**实战训练**还要 100+ 道题 |
| "跳级一定不好" | 不绝对。**有训练基础**的娃可以跳，**没训练基础**的强跳容易底虚 |
