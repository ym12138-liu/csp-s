### 阶段 B：图论四大算法（5 周，**核心**）

**算法 1 · Kruskal 最小生成树（边优先）**
```cpp
// 思路：所有边按权值升序 + 并查集逐条加边（避免成环）
struct Edge { int u, v, w; };
bool cmp(Edge a, Edge b) { return a.w < b.w; }

int fa[N];
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }

int kruskal(int n, vector<Edge>& edges) {
    sort(edges.begin(), edges.end(), cmp);
    for (int i = 1; i <= n; i++) fa[i] = i;
    int sum = 0, cnt = 0;
    for (auto& e : edges) {
        int fu = find(e.u), fv = find(e.v);
        if (fu == fv) continue;
        fa[fu] = fv;
        sum += e.w;
        if (++cnt == n - 1) break;
    }
    return sum;
}
// 复杂度 O(m log m)
```

**算法 2 · Prim 最小生成树（点优先）**
```cpp
// 思路：从某一点出发，每次加入"距生成树最近"的点
int prim(int n, int g[][N]) {
    vector<int> dist(n + 1, INT_MAX);
    vector<bool> in(n + 1, false);
    dist[1] = 0;
    int sum = 0;
    for (int i = 0; i < n; i++) {
        int u = -1;
        for (int j = 1; j <= n; j++)
            if (!in[j] && (u == -1 || dist[j] < dist[u])) u = j;
        if (dist[u] == INT_MAX) return -1;   // 不连通
        in[u] = true;
        sum += dist[u];
        for (int v = 1; v <= n; v++)
            if (!in[v] && g[u][v] < dist[v])
                dist[v] = g[u][v];
    }
    return sum;
}
// 复杂度 O(n²)，堆优化后 O(m log n)
```

**算法 3 · Dijkstra 单源最短路**
```cpp
// 朴素 O(n²)
int dist[N];
bool vis[N];
void dijkstra(int s, int n, int g[][N]) {
    fill(dist, dist + n + 1, INT_MAX);
    dist[s] = 0;
    for (int i = 0; i < n; i++) {
        int u = -1;
        for (int j = 1; j <= n; j++)
            if (!vis[j] && (u == -1 || dist[j] < dist[u])) u = j;
        vis[u] = true;
        for (int v = 1; v <= n; v++)
            if (g[u][v] != INT_MAX && dist[u] + g[u][v] < dist[v])
                dist[v] = dist[u] + g[u][v];
    }
}
```

**Dijkstra 堆优化 O((n+m) log n)**
```cpp
priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;
pq.push({0, s});
dist[s] = 0;
while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (d > dist[u]) continue;
    for (auto [v, w] : adj[u]) {
        if (dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w;
            pq.push({dist[v], v});
        }
    }
}
```

**算法 4 · Floyd 多源最短路 O(n³)**
```cpp
// 注意三层循环顺序：k 必须在最外层！
for (int k = 1; k <= n; k++)
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            if (dist[i][k] + dist[k][j] < dist[i][j])
                dist[i][j] = dist[i][k] + dist[k][j];
```

**四算法对比（必背）：**
| 算法 | 用途 | 复杂度 | 是否处理负权 |
|---|---|---|---|
| Kruskal | 最小生成树 | O(m log m) | 否 |
| Prim | 最小生成树 | O(n²) / O(m log n) | 否 |
| Dijkstra | 单源最短路 | O(n²) / O((n+m) log n) | **不能**处理负权 |
| Floyd | 全源最短路 | O(n³) | 可处理负权（无负环） |

### 阶段 C：组合数学（3 周）

**核心公式（必背）：**
```
排列：A(n,k) = n! / (n-k)!
组合：C(n,k) = n! / (k!(n-k)!)
       = C(n-1,k-1) + C(n-1,k)   (杨辉三角递推)
二项式：(a+b)^n = ΣC(n,k)·a^(n-k)·b^k
错排：D(n) = (n-1)·(D(n-1) + D(n-2))
卡特兰：C(n) = C(2n,n) / (n+1)
```

**杨辉三角 DP（求组合数）**
```cpp
int C[N][N] = {0};
for (int i = 0; i <= n; i++) {
    C[i][0] = 1;
    for (int j = 1; j <= i; j++) {
        C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD;
    }
}
```

**经典模型：**
| 题型 | 公式 |
|---|---|
| n 不同元素全排列 | n! |
| 从 n 选 k（顺序无关） | C(n,k) |
| n 个相同元素分 k 组（每组至少 1） | C(n-1, k-1) |
| 球放盒（4 种情况） | 看 球同/不同 + 盒同/不同 |
| 出栈序列数 | 卡特兰数 C(n) |
| 凸 n 多边形剖分三角形 | C(n-2) |
| n 个人 全错排（自己拿不到自己） | D(n) |

### 阶段 D：高级 DP（3 周）

**LCS 滚动数组优化（七级深化）**
```cpp
int dp[2][1005];
for (int i = 1; i <= n; i++) {
    int cur = i & 1, prev = !cur;
    for (int j = 1; j <= m; j++) {
        if (a[i-1] == b[j-1])
            dp[cur][j] = dp[prev][j-1] + 1;
        else
            dp[cur][j] = max(dp[prev][j], dp[cur][j-1]);
    }
}
```

**树形 DP 入门 · 没有上司的舞会**
```cpp
// dp[u][0] = 不选 u 时 u 子树最大开心
// dp[u][1] = 选 u 时 u 子树最大开心
void dfs(int u, int parent) {
    dp[u][0] = 0;
    dp[u][1] = h[u];
    for (int v : adj[u]) {
        if (v == parent) continue;
        dfs(v, u);
        dp[u][0] += max(dp[v][0], dp[v][1]);
        dp[u][1] += dp[v][0];   // 选了 u，子节点不能选
    }
}
```

**区间 DP 入门 · 石子合并**
```cpp
// dp[l][r] = 合并 [l, r] 的最小代价
for (int len = 2; len <= n; len++) {
    for (int l = 1; l + len - 1 <= n; l++) {
        int r = l + len - 1;
        dp[l][r] = INT_MAX;
        for (int k = l; k < r; k++) {
            dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + sum[r] - sum[l-1]);
        }
    }
}
```

```cpp
class Point {
public:
```

```cpp
int a = 10;
```

### 阶段 F：排序最坏情况（1 周）

**快排最坏：** 每次选的 pivot 都是最大或最小 → O(n²)（如**已排序**或**全相同**输入）

**避免方法：** 随机选 pivot 或"三数取中"

**注意：** 即使随机化也**不能完全避免**最坏情况，只是概率极低

**归并排序：** 始终 O(n log n)，**最坏 = 最好 = 平均**

**稳定性大表：**
| 算法 | 平均 | 最坏 | 稳定 |
|---|---|---|---|
| 冒泡 | O(n²) | O(n²) | √ |
| 选择 | O(n²) | O(n²) | × |
| 插入 | O(n²) | O(n²) | √ |
| 归并 | O(n log n) | O(n log n) | √ |
| 快排 | O(n log n) | **O(n²)** | × |
| 堆排 | O(n log n) | O(n log n) | × |
| 计数 | O(n+k) | O(n+k) | √ |

### 阶段 G：概率论（1 周）

**古典概率：** P(A) = 有利情形数 / 总情形数

**几何概率：** P(A) = 有利区域大小 / 总区域大小

**经典题型：**
- 单位圆上 n 个点都被某半圆覆盖的概率
- 路口判断方向（说真话 / 说谎话）

---

### 阶段 H：卡特兰数 / 错排（1 周）

**卡特兰数：** `C(n) = C(2n,n) / (n+1)` 或 `C(n) = ΣC(i)·C(n-1-i)`

**应用：**
- n 对括号合法序列数
- n 个不同元素**入栈出栈**的方案数
- 凸 n+2 边形的三角剖分数
- n 个节点的不同二叉树数

**错排：** `D(n) = (n-1)(D(n-1) + D(n-2))` · 必背 D(1)..D(6) = 0, 1, 2, 9, 44, 265

## 3. 编程题套路集合

### 套路 1 · Dijkstra 应用
```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 1e5+5;
vector<pair<int,int>> adj[N];
int dist[N];
void dij(int s, int n) {
    fill(dist, dist+n+1, INT_MAX);
    dist[s] = 0;
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;
    pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;
        for (auto [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
}
```

### 套路 2 · Kruskal 最小生成树
```cpp
struct Edge { int u, v, w; };
bool cmp(Edge a, Edge b) { return a.w < b.w; }
int fa[N];
int find(int x) { return fa[x]==x ? x : fa[x] = find(fa[x]); }
```

## 5. 必背代码小卡片（**收藏 + 抄 5 遍**）

```cpp
// 1. Kruskal MST
struct E { int u,v,w; };
bool cmp(E a, E b){ return a.w<b.w; }
int fa[N];
int find(int x){ return fa[x]==x ? x : fa[x]=find(fa[x]); }
int kru(int n, vector<E>& e) {
    sort(e.begin(),e.end(),cmp);
    for(int i=1;i<=n;i++) fa[i]=i;
    int s=0, c=0;
    for(auto& x:e) {
        int fu=find(x.u), fv=find(x.v);
        if(fu==fv) continue;
        fa[fu]=fv; s+=x.w;
        if(++c==n-1) break;
    }
    return s;
}

// 2. Dijkstra 堆优化
priority_queue<pii, vector<pii>, greater<>> pq;
pq.push({0,s}); d[s]=0;
while(!pq.empty()) {
    auto [dv,u]=pq.top(); pq.pop();
    if(dv>d[u]) continue;
    for(auto [v,w]:adj[u])
        if(d[u]+w<d[v]) {
            d[v]=d[u]+w;
            pq.push({d[v],v});
        }
}

// 3. Floyd
for(int k=1;k<=n;k++)
    for(int i=1;i<=n;i++)
        for(int j=1;j<=n;j++)
            d[i][j] = min(d[i][j], d[i][k]+d[k][j]);

// 4. 组合数（杨辉三角）
C[0][0]=1;
for(int i=1;i<=n;i++) {
    C[i][0]=1;
    for(int j=1;j<=i;j++)
        C[i][j] = (C[i-1][j-1]+C[i-1][j]) % MOD;
}

// 5. 树形 DP（最大独立集）
void dfs(int u, int p) {
    dp[u][0]=0; dp[u][1]=w[u];
    for(int v:adj[u]) if(v!=p) {
        dfs(v,u);
        dp[u][0] += max(dp[v][0], dp[v][1]);
        dp[u][1] += dp[v][0];
    }
}

// 6. LCS 滚动数组
for(int i=1;i<=n;i++) {
    int c=i&1, p=!c;
    for(int j=1;j<=m;j++)
        dp[c][j] = (a[i-1]==b[j-1])
            ? dp[p][j-1]+1
            : max(dp[p][j], dp[c][j-1]);
}
```

## 6. 常见误区 & 提醒
