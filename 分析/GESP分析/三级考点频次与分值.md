## 2. 三级 vs 二级 · 关键升级点

| 维度 | 二级 | 三级 |
|---|---|---|
| 进制 | 仅基本字面量（010 / 0x10） | **完整进制转换**（2/8/10/16 互转） |
| 位运算 | 不考 | **必考**（& \| ^ ~ << >>） |
| 编码 | 不考 | **原码 / 反码 / 补码** |
| 字符串 | cin/cout 入门 | **strcmp / strlen / 字符串遍历** |
| 函数 | 不考 | **C++ 内置函数**（min/max/abs/pow） |
| 运算符 | 算术 + 关系 + 逻辑 | **新增三目（? :）** |
| 复杂判断 | 多条件 if | **流程图 / 逻辑推理** |
| 编程题 | 数组遍历 + if | **进制转换 / 字符串 / 数组进阶** |

## 5. 编程题考点统计（10 场 × 2 题 = 20 段）

| 题型 | 出现次数 | 难度 | 套路 |
|---|---|---|---|
| 进制转换实现 | ≈ 4 / 20 | 中等 | 循环取余 + 拼接 |
| 字符串处理（含字符替换 / 计数） | ≈ 5 / 20 | 中等 | 字符串遍历 + 条件 |
| 数组进阶（排序 / 极值 / 计数） | ≈ 5 / 20 | 中等 | 数组 + 多重循环 |
| 数学应用（含位运算 / 数位） | ≈ 4 / 20 | 中等 | 单循环 + 位运算 / 取模 |
| 简单模拟题 | ≈ 2 / 20 | 中等 | 多步骤模拟 |

**编程题升级特征：**
- 数据范围 n ≤ 10⁵
- 标准代码长度 20-30 行
- 主要使用：数组 + 字符串 + 简单循环
- 偶尔需要：位运算、内置函数

## 6. 时间轴：10 场命题趋势

| 考期 | 命题特点 |
|---|---|
| 2023.12 | 三级首场 · 进制题保守 |
| 2024.03 | 位运算题增加 |
| 2024.06 | 字符串处理题占比上升 |
| 2024.09 | **位运算 + 补码出题量爆发** |
| 2024.12 | 数组进阶题增多 |
| 2025.03 | 流程图阅读 + 逻辑推理首次 |
| 2025.06 | 字符串 + 内置函数为主 |
| 2025.09 | 难度趋于稳定 |
| 2025.12 | 综合应用题（位运算 + 数组）高频 |
| 2026.03 | 编程题模板化 |

**整体趋势：**
1. **位运算 + 进制是三级"门票"** — 不熟练直接丢 20+ 分
2. **字符串题持续增加** — 二级浅尝辄止 → 三级深入
3. **C++ 内置函数**进入考点 — 必须会 min/max/abs/pow
4. **流程图 + 逻辑推理**这种"另类题型"出现 — 考查综合能力
