## 2. 六级 vs 五级 · 关键升级点

| 维度 | 五级 | 六级 |
|---|---|---|
| 编程范式 | 面向过程 + 函数 | **新增面向对象（类 / 继承 / 多态）** |
| 数据结构 | 链表 | **新增二叉树 / 二叉搜索树 / 栈队列应用** |
| 树 | 不考 | **必考前/中/后序遍历、完全二叉树性质** |
| 算法思想 | 贪心 / 分治 | **新增 DFS / BFS / 动态规划** |
| DP | 不考 | **入门：0-1 背包 / 爬楼梯** |
| 编码 | 简单计算 | **新增哈夫曼编码 / 格雷码** |

> **结论：** 六级是 GESP 体系的**核心数据结构关**，对接 CSP-J 复赛。

## 5. 编程题考点统计（10 场 × 2 题 = 20 段）

| 题型 | 出现次数 | 难度 | 套路 |
|---|---|---|---|
| 二叉树构造 / 遍历 | ≈ 5 / 20 | 中等 | 递归 + 遍历 |
| BST 插入 / 查找 / 判断 | ≈ 4 / 20 | 中等 | 递归实现 |
| DP 应用题（背包 / 路径） | ≈ 4 / 20 | 中等偏难 | 状态转移 |
| 栈 / 队列应用题 | ≈ 3 / 20 | 中等 | 数据结构操作 |
| 图 BFS / DFS（简单图） | ≈ 2 / 20 | 中等 | 邻接矩阵 + 队列 |
| 综合应用 / 哈夫曼 | ≈ 2 / 20 | 中等偏难 | 多阶段算法 |

**编程题升级特征：**
- 数据范围 n ≤ 10⁴-10⁵
- 标准代码长度 40-60 行
- 主要使用：树 / DP / 队列 / 哈希
- 必须会：树的递归遍历 + 简单 DP 状态转移
