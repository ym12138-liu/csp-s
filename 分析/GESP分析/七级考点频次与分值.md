## 2. 七级 vs 六级 · 关键升级点

| 维度 | 六级 | 七级 |
|---|---|---|
| 图论 | 不考 | **必考**（无向 / 有向 / 强连通 / 生成树） |
| 搜索 | 树上 DFS / BFS | **图上 DFS / BFS / Flood Fill** |
| 哈希 | 不考 | **必考**（哈希表 / 冲突处理） |
| DP | 入门（0-1 背包） | **进阶**（LCS + 滚动数组 + 复杂背包） |
| 复杂度 | 简单分析 | **新增递推式分析（主定理）** |
| 字符串 | 简单遍历 | **加深 strcmp / 字符串编码** |
| 编程题 | 树 + DP | **图论 + 综合 DP + 哈希应用** |

> **结论：** 七级是 GESP 体系**对接 CSP-J 复赛主战场**的一级，新增图论是最大跨越。

## 6. 时间轴：10 场命题趋势

| 考期 | 命题特点 |
|---|---|
| 2023.12 | 七级首场 · 树 + 简单图论 |
| 2024.03 | 引入哈希冲突题 |
| 2024.06 | 强连通分量首次出现 |
| 2024.09 | **图论 + 哈希齐发**（5 题以上） |
| 2024.12 | LCS 进入编程题 |
| 2025.03 | 难度抬升 · 综合应用题增多 |
| 2025.06 | 题型趋稳 |
| 2025.09 | OOP + 图论结合考查 |
| 2025.12 | **递推式复杂度** + 图论 + 哈希齐发 |
| 2026.03 | 编程题模板化 |

**整体趋势：**
1. **图论是七级"门票"** — 不熟练丢 30+ 分
2. **哈希表年年考** — 冲突 / 函数 / 效率三个角度轮换
3. **DP 深化** — 不只是 0-1 背包，开始考 LCS + 滚动数组
4. **复杂度题更深** — 递推式分析进入考点
5. **强连通分量 / 生成树** 成为图论高频
