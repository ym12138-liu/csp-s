## 2. 四级 vs 三级 · **关键大跨越**

| 维度 | 三级 | 四级 |
|---|---|---|
| 数据类型 | 基本类型 + 数组 | **新增指针、引用、结构体** |
| 数组维度 | 一维 | **新增二维数组** |
| 函数 | 仅内置函数 | **必考自定义函数 + 形参实参** |
| 算法 | 简单遍历 | **必考三种排序（冒泡 / 选择 / 插入）** |
| 复杂度 | 不考 | **新增时间复杂度分析（O 表示法）** |
| 算法思想 | 简单循环 | **新增递推 / 递归（深入）** |
| 文件 | 不考 | **新增文件重定向 / 异常处理（少量）** |
| 编程题 | 数组 + 字符串 | **结构体应用 / 排序应用 / 函数封装** |

> **结论：** 四级是 GESP 体系**最重要的分水岭**。从这里开始进入"算法 + 复杂度"思维，之前的"操作语法"思维不够用。

## 5. 编程题考点统计（10 场 × 2 题 = 20 段）

| 题型 | 出现次数 | 难度 | 套路 |
|---|---|---|---|
| 排序应用题（冒泡 / 选择 / 插入实现） | ≈ 6 / 20 | 中等 | 双重循环 + 交换 |
| 结构体数组（学生 / 玩家 / 商品） | ≈ 5 / 20 | 中等 | 结构体 + 排序 |
| 二维数组应用（矩阵 / 棋盘） | ≈ 4 / 20 | 中等 | 双层 for 遍历 |
| 函数封装题（自定义函数解决） | ≈ 4 / 20 | 中等 | 函数 + 数组 |
| 简单算法（递推 / 模拟） | ≈ 1 / 20 | 中等 | 单循环 |

**编程题升级特征：**
- 数据范围 n ≤ 10⁴-10⁵
- 标准代码长度 30-50 行
- 主要使用：结构体 + 数组 + 函数 + 排序
- 必须会：自定义比较函数、二维数组遍历

## 6. 时间轴：10 场命题趋势

| 考期 | 命题特点 |
|---|---|
| 2023.12 | 首场 · 函数 + 数组为主 |
| 2024.03 | 引入指针概念 |
| 2024.06 | 排序算法首次成核心考点 |
| 2024.09 | **排序题 + 复杂度题大量出现**（5 题以上） |
| 2024.12 | 结构体 + 二维数组比重上升 |
| 2025.03 | 综合应用题占比抬升 |
| 2025.06 | 难度趋于稳定 |
| 2025.09 | 引入更多指针进阶题（指针接力） |
| 2025.12 | **指针 + 二维数组 + 结构体三块齐发** |
| 2026.03 | 编程题模板化 |

**整体趋势：**
1. **指针题年年加重** — 2025.12 单选 1-7 都涉及指针
2. **排序算法是必拿分** — 三种排序都要熟
3. **二维数组成新主流** — 棋盘 / 矩阵题持续考
4. **复杂度分析进入主流** — 不会判 O(n²) 直接丢分
5. **结构体题在稳定增加**
