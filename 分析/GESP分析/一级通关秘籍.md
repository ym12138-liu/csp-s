## 2. 学习阶段（建议 4-8 周）

### 阶段 A：C++ 语法地基（1-2 周）

**学习目标：** 看到 10 行内的 C++ 代码能正确判断输出。

**清单：**
1. **基本数据类型**
   - `int` 整型 · `float` / `double` 浮点 · `char` 字符 · `bool` 布尔
   - `int` 范围一般 ±21 亿（32 位）
2. **变量命名规则（必背）**
   - 必须以**字母或下划线**开头
   - 只能含**字母、数字、下划线**
   - **不能用关键字**（`int`、`for`、`if`、`return`、`cout`、`cin` 等）
   - 不能含 `-`、`+`、空格、中文
3. **常量与字面量**
   - 整数：`10` / `010`（八进制）/ `0x1A`（十六进制）
   - 字符：`'A'`（单引号）— **注意不是 `"A"`**
   - 字符串：`"Hello"`（双引号）
   - 转义：`\n` 换行 · `\t` 制表 · `\\` 反斜杠

**练手：**
- 默写 5 个合法变量名 + 5 个非法变量名
- 写一个 `cout << "Hello, GESP!" << endl;` 跑通

---

### 阶段 B：运算符与表达式（1 周，**最重要**）

**关键易错点（每场都考）：**

| 表达式 | 结果 | 说明 |
|---|---|---|
| `10 / 3` | `3` | 整数除法 → 截断 |
| `10 % 3` | `1` | 取模 |
| `10.0 / 3` | `3.333...` | 浮点除法 |
| `5 + 3 * 2` | `11` | * 优先级高于 + |
| `(5 + 3) * 2` | `16` | 括号优先 |
| `010` | `8`（八进制） | 数字 0 开头 |
| `'A' + 1` | `66`（数值） | char 参与运算变 int |
| `++a` | a 先加 1 再用 | 前置 |
| `a++` | a 先用再加 1 | 后置 |
| `5 / 2 * 2` | `4` | 不是 5！整除丢精度 |

**优先级口诀（从高到低）：**
1. `()` 括号
2. `++ --` 一元
3. `* / %` 乘除取模
4. `+ -` 加减
5. `< <= > >=` 比较
6. `== !=` 等于
7. `&&` 与
8. `||` 或
9. `=` 赋值（最低）

### 阶段 C：流程控制（2 周）

**模板 1 · if / else**
```cpp
if (条件) {
    // 满足时执行
} else if (另一条件) {
    // ...
} else {
    // 都不满足
}
```

**模板 2 · for 循环（次数已知）**
```cpp
for (int i = 0; i < n; i++) {
    // 循环体
}
```

**模板 3 · while 循环（条件控制）**
```cpp
while (条件) {
    // 循环体
}
```

**易错点：**
- `for(int i=1; i<=10; i+=3)` → i = 1, 4, 7, 10（4 次）
- `for(int i=0; i<10; i+=2)` → i = 0, 2, 4, 6, 8（5 次）
- `break` = 立刻**跳出**整个循环
- `continue` = **跳过本次**剩余代码，进入下次循环
- `while(1)` 不带 break = **死循环**

**坑题示例（不复述，只描述套路）：**
- 给一段 `for` 循环里有 `i++`，问执行了几次 → 数清楚循环条件何时不满足
- `if(P % 3 || P % 7)` 这种条件 → 注意 `||` 短路求值

### 阶段 D：输入输出（3 天）

**4 种 IO 必会：**
```cpp
// 1. C++ 流式输入
cin >> a >> b;       // 多个变量用 >> 连接
// 2. C++ 流式输出
cout << a << " " << b << endl;
// 3. C 风格格式化输入
scanf("%d", &a);     // 注意 & 取地址
// 4. C 风格格式化输出
printf("%d, %d\n", a, b);
```

**printf 格式符（必背）：**
| 符号 | 含义 |
|---|---|
| `%d` | int 整数 |
| `%f` | float 浮点 |
| `%s` | 字符串 |
| `%c` | 字符 |
| `%%` | 字面 % 号 |
| `%2d` | 至少 2 位宽度 |

**坑题：**
- `printf("5%%2={%d}", 5%2)` → 输出 `5%2={1}`（`%%` 是字面 %）
- `cout << (3, 2)` → 输出 `2`（逗号表达式取最后一个值）

### 阶段 E：编程题模板（持续）

**典型套路 1：求满足条件的数的个数**
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;
    int ans = 0;
    for (int i = 0; i < n; i++) {
        int x; cin >> x;
        if (/* 条件，比如 x % 9 == 0 && x % 8 != 0 */) ans++;
    }
    cout << ans << endl;
    return 0;
}
```
> **15 行模板**适用于 70% 的编程题第 2 题。

**典型套路 2：简单数学（一次性算）**
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, a, b;
    cin >> n >> a >> b;
    cout << n / (a + b) << endl;  // 直接公式
    return 0;
}
```
> 编程题第 1 题经常是这种"读数 → 一次运算 → 输出"。

**典型套路 3：循环求和 / 累加**
```cpp
int sum = 0;
for (int i = 1; i <= n; i++) {
    sum += i;
}
cout << sum;
```

**典型套路 4：求位数**
```cpp
int rc = 0;
while (n) {
    rc++;
    n /= 10;
}
cout << rc;
```

## 6. 必背代码小卡片（**收藏 + 抄 3 遍**）

```cpp
// === 1. 输入 N 个数，按条件计数 ===
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, ans = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {
        int x; cin >> x;
        if (/* 条件 */) ans++;
    }
    cout << ans << endl;
    return 0;
}

// === 2. 判断质数 ===
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}

// === 3. 求一个数的位数 ===
int countDigit(int n) {
    int rc = 0;
    while (n) { rc++; n /= 10; }
    return rc;
}

// === 4. 求 1 到 N 的和 ===
int sum = 0;
for (int i = 1; i <= n; i++) sum += i;
```
