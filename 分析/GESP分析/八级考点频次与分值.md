## 2. 八级 vs 七级 · 关键升级点

| 维度 | 七级 | 八级 |
|---|---|---|
| 图论算法 | BFS / DFS / 强连通 | **必考四大算法**（Kruskal / Prim / Dijkstra / Floyd） |
| 数学 | 简单组合 | **必考排列组合 + 二项式 + 概率 + 卡特兰** |
| DP 难度 | LCS / 0-1 背包 | **新增滚动数组 LCS / 杨辉三角 / 树形 DP** |
| OOP | 入门 | **新增多构造函数 / 引用 / 继承访问权限** |
| 排序 | 三种基础 | **快排 / 归并的最坏情况、随机化** |
| 综合度 | 单点知识 | **多种数据结构组合应用** |

> **结论：** 八级是 GESP 体系**最高级**，难度对应 **CSP-S 初赛中等水平 / CSP-J 复赛拿奖水平**。

## 6. 时间轴：10 场命题趋势

| 考期 | 命题特点 |
|---|---|
| 2023.12 | 八级首场 · 图论算法初考 |
| 2024.03 | 排列组合题增加 |
| 2024.06 | 高级 DP 进入考点 |
| 2024.09 | **图论四大算法齐发**（Kruskal/Prim/Dijkstra/Floyd 同卷出现） |
| 2024.12 | 卡特兰数 / 概率题首考 |
| 2025.03 | 综合应用题占比抬升 |
| 2025.06 | 题型趋稳 |
| 2025.09 | 题量 / 难度抬升明显（11 页 + 11299 字符） |
| 2025.12 | **图论 + 组合 + DP**三大块齐发 |
| 2026.03 | 编程题模板化 |

**整体趋势：**
1. **图论算法是八级"门票"** — 四大算法不熟练直接挂
2. **组合数学占比稳定 10%** — 排列组合 / 二项式必考
3. **快排 + 归并的对比题年年都有**
4. **OOP 题数量稳定** — 引用 / 多构造 / 继承
5. **概率题开始进入** — 几何概率 + 古典概率
