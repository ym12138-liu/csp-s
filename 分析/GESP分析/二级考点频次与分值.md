## 2. 二级 vs 一级 · 关键升级点

| 维度 | 一级 | 二级 |
|---|---|---|
| 数据结构 | 仅基本类型 | **新增一维数组** |
| 循环 | 单层 for / while | **新增多层嵌套** |
| 递归 | 不考 | **简单递归（Fib / 阶乘）** |
| 字符串 | 仅 char | **新增 cin/cout 字符串、简单遍历** |
| 图形输出 | 不考 | **新增 N×N 字符图形** |
| 算法主题 | 求和 / 求位数 | **新增孪生素数 / 自守数 / 阶乘和** |
| 计算机基础 | 时事 + 历史 | **新增网络（IPv4 / TCP）、存储单位** |
| 编程题难度 | 单循环 + 单 if | **多循环 / 数组遍历 / 复合条件** |

## 5. 编程题考点统计（10 场 × 2 题 = 20 段）

| 题型 | 出现次数 | 难度 | 套路 |
|---|---|---|---|
| 数组遍历计数（满足条件的元素个数） | ≈ 8 / 20 | 简单 | 一维数组 + if |
| 数组求最值 / 求和 | ≈ 4 / 20 | 简单 | 单循环 + max/min |
| 多条件判断（漂亮数 / 美丽数 / 相关数） | ≈ 5 / 20 | 中等 | 多重 if，常含数位提取 |
| 简单数学应用题（购物 / 阶乘 / 排列） | ≈ 3 / 20 | 简单 | 一次性公式 |

**编程题共同特征：**
- 数据范围 n ≤ 10⁴ 量级
- 标准代码长度 15-25 行
- 主要使用：一维数组 + 单/双重循环 + if
- 不需要：递归、STL 容器、字符串高级操作

## 6. 时间轴：10 场命题趋势

| 考期 | 命题特点 |
|---|---|
| 2023.12 | 二级首场 · 数组题占比保守 |

| 2024.06 | 字符 ASCII 题增多 |
| 2024.09 | 计算机网络（IPv4）首次进入 |
| 2024.12 | 九九乘法表 + 多条件判断升级 |
| 2025.03 | DeepSeek + 哪吒 2 时事 |
| 2025.06 | 自守数 + 图形输出难度抬升 |
| 2025.09 | 大模型 + TCP 三次握手 |
| 2025.12 | 复杂条件题（编码规则 / 漂亮数）多 |

**整体趋势：**
1. **网络题年年增加** — 从 0 题/卷上升到 1-2 题/卷
2. **数组题分值稳定占 8-10%** — 是二级最大的能力跨越
3. **图形输出题持续高频** — 几乎每场必出 1 题
4. **多条件判断（漂亮数 / 自守数）成为编程题主流**
