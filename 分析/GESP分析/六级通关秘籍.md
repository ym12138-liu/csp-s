### 阶段 B：二叉树（3 周，**核心**）

**模板 1 · 二叉树节点定义**
```cpp
struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};
```

**模板 2 · 三种遍历（递归版）**
```cpp
// 前序：根 → 左 → 右
void preorder(TreeNode* root) {
    if (!root) return;
    cout << root->val << ' ';
    preorder(root->left);
    preorder(root->right);
}
// 中序：左 → 根 → 右
void inorder(TreeNode* root) {
    if (!root) return;
    inorder(root->left);
    cout << root->val << ' ';
    inorder(root->right);
}
// 后序：左 → 右 → 根
void postorder(TreeNode* root) {
    if (!root) return;
    postorder(root->left);
    postorder(root->right);
    cout << root->val << ' ';
}
```

**模板 3 · 树的深度（DFS / BFS）**
```cpp
// DFS 递归
int depth(TreeNode* root) {
    if (!root) return 0;
    return max(depth(root->left), depth(root->right)) + 1;
}

// BFS 用队列
int depthBFS(TreeNode* root) {
    if (!root) return 0;
    queue<TreeNode*> q;
    q.push(root);
    int d = 0;
    while (!q.empty()) {
        int sz = q.size();
        for (int i = 0; i < sz; i++) {
            auto p = q.front(); q.pop();
            if (p->left) q.push(p->left);
            if (p->right) q.push(p->right);
        }
        d++;
    }
    return d;
}
```

**关键技能 · 已知两种遍历推第三种**

| 已知 | 思路 |
|---|---|
| 前序 + 中序 → 后序 | 前序首位是根；中序中根左右切左右子树；递归 |
| 后序 + 中序 → 前序 | 后序末位是根；中序切左右；递归 |
| 前序 + 后序 → 中序 | **不唯一**（除非满二叉树） |

**口诀：** "**中序找根分左右**，前/后序认根"。

**完全二叉树性质（必背）：**
- 节点 `i` 的父：`i/2`
- 节点 `i` 的左子：`2i`，右子：`2i+1`
- 高度为 `h` 的完全二叉树节点数：`[2^(h-1), 2^h - 1]`
- n 节点完全二叉树叶子数 ≈ `n - n/2 = ⌈n/2⌉`

### 阶段 C：二叉搜索树 BST（1 周）

**性质：** 左子树所有节点 < 根 < 右子树所有节点

**模板 1 · BST 查找**
```cpp
TreeNode* search(TreeNode* root, int x) {
    if (!root || root->val == x) return root;
    if (x < root->val) return search(root->left, x);
    return search(root->right, x);
}
```

**模板 2 · BST 插入**
```cpp
TreeNode* insert(TreeNode* root, int x) {
    if (!root) return new TreeNode(x);
    if (x < root->val) root->left = insert(root->left, x);
    else if (x > root->val) root->right = insert(root->right, x);
    return root;
}
```

**模板 3 · 验证是否 BST（易错）**
```cpp
// 用中序遍历，序列必须严格升序
bool isBST(TreeNode* root, long& prev) {
    if (!root) return true;
    if (!isBST(root->left, prev)) return false;
    if (root->val <= prev) return false;
    prev = root->val;
    return isBST(root->right, prev);
}
```

> **常见错误：** 仅判断"`root->val > root->left->val && root->val < root->right->val`"是错的，必须**整棵子树**都满足。

### 阶段 D：栈与队列应用（1 周）

**栈 · 括号匹配**
```cpp
bool match(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') st.push(c);
        else {
            if (st.empty()) return false;
            char t = st.top(); st.pop();
            if ((c == ')' && t != '(') ||
                (c == ']' && t != '[') ||
                (c == '}' && t != '{')) return false;
        }
    }
    return st.empty();
}
```

**栈 · 撤销操作（编辑器场景）**
```cpp
stack<char> st;
// 输入字符
st.push(c);
// 撤销 = 弹出栈顶
if (!st.empty()) st.pop();
```

**循环队列**
```cpp
const int N = 100;
int q[N], front = 0, rear = 0;

bool isEmpty() { return front == rear; }
bool isFull()  { return (rear + 1) % N == front; }

void push(int x) {
    if (isFull()) return;
    q[rear] = x;
    rear = (rear + 1) % N;
}
int pop() {
    if (isEmpty()) return -1;
    int x = q[front];
    front = (front + 1) % N;
    return x;
}
```

> **判断题坑：** 循环队列的"队空"和"队满"判断都用模运算，**容易混淆**。

### 阶段 E：面向对象 OOP（2 周）

**模板 1 · 类的定义**
```cpp
class Animal {
private:
    string name;
public:
    Animal(string n) : name(n) {}     // 构造函数
    virtual void sound() {            // 虚函数（多态基础）
        cout << "动物叫" << endl;
    }
};

class Dog : public Animal {           // 继承
public:
    Dog(string n) : Animal(n) {}
    void sound() override {           // 多态：重写
        cout << "汪汪" << endl;
    }
};
```

**OOP 三大特性（必背）：**
| 特性 | 含义 | 关键字 |
|---|---|---|
| **封装** | 数据 + 操作绑定，对外隐藏细节 | private / public |
| **继承** | 子类拥有父类的属性和方法 | `: public Base` |
| **多态** | 同名方法在不同对象表现不同 | virtual / override |

**构造函数顺序（判断题考点）：**
- 创建派生类对象时：**先调用基类构造函数 → 再调用派生类构造函数**
- 析构顺序相反：**先派生 → 再基类**

### 阶段 F：动态规划入门（2 周）

**核心思想：** 大问题 = 小问题的解 + 状态转移。

**模板 1 · 爬楼梯**
```cpp
// f[i] = f[i-1] + f[i-2]，f[1]=1, f[2]=2
int climb(int n) {
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) {
        int c = a + b; a = b; b = c;
    }
    return n == 1 ? 1 : b;
}
```

**模板 2 · 0-1 背包（一维 DP）**
```cpp
// n 个物品，容量 V
// dp[j] = 容量 j 时的最大价值
int dp[1005] = {0};
for (int i = 0; i < n; i++) {
    for (int j = V; j >= w[i]; j--) {       // 必须倒序！
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
cout << dp[V];
```

**关键点（判断题易考）：**
- 0-1 背包**第二层倒序**才能保证每个物品最多用一次
- DP 必须有：**重叠子问题** + **最优子结构**
- 状态转移方程是 DP 的核心

### 阶段 G：哈夫曼编码（半周）

**思想：** 频率高的字符用短编码，频率低的用长编码。

**构建步骤：**
1. 把所有字符按频率放入小根堆
2. 每次取出两个最小频率，合并成新节点（权值=两者之和）
3. 重复直到只剩一个根节点
4. 根→叶子的路径就是编码（左 0 右 1）

**口诀：** **每次合并最小两个 → 总编码长度（带权路径长度 WPL）= 所有非叶子节点权值之和**。

int countLeaf(TreeNode* root) {

int main() {

queue<pair<int,int>> q;
q.push({sx, sy});

## 6. 常见误区 & 提醒

| 误区 | 真相 |
|---|---|
| "树的递归很难懂" | **画 5 棵树**逐题手追，递归就懂了 |
| "BST 判断只看本节点" | 必须用**中序遍历升序**或**带边界递归**判断 |
| "DP 看代码就能写" | 必须理解**状态定义**和**转移方程**才能写出来 |
| "OOP 不重要" | 六级**至少 5 题**OOP，**80% 必练** |
| "BFS 用栈也行" | **错！** BFS 必须用**队列**，DFS 用栈/递归 |
| "0-1 背包顺序倒序无所谓" | **必须倒序**！否则变成完全背包 |
