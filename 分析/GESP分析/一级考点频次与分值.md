## 4. 编程题考点统计（10 场 × 2 题 = 20 段）

| 题型 | 出现次数 | 难度 | 典型代表 |
|---|---|---|---|
| 简单数学应用题（除法 / 取模 / 计数） | ≈ 12 / 20 | 极简 | 购买商品、整除计数、美丽数字 |
| 数字运算（求和 / 平均 / 极值） | ≈ 5 / 20 | 简单 | 给定 N 个数求满足条件的个数 |
| 字符 / 字符串（少量） | ≈ 2 / 20 | 中等 | 判断字符类型 |
| 简单逻辑判断（条件分支） | ≈ 1 / 20 | 简单 | 三角形是否合法等 |

**编程题共同特征：**
- 数据范围都很小（n ≤ 1000 量级）
- 一个 `for` 循环 + 几个 `if` 即可解决
- 不需要数组、字符串、函数等进阶语法
- 标准代码长度 ≤ 15 行

## 5. 时间轴：10 场命题趋势

| 考期 | 命题特点 |
|---|---|
| 2023.12 | 首场 · 单选偏向语法基础 + 简单输出 |
| 2024.03 | 加入"鸿蒙"等时事题 |
| 2024.06 | 加入"王选奖 / GESP 自身"等元题 |
| 2024.09 | 计算机历史出题（山东大学 DJL-1） |
| 2024.12 | 加入诺贝尔 + 操作系统辨识 |
| 2025.03 | DeepSeek / 哪吒 2 时事元素显著 |
| 2025.06 | 引入"调试 / 断点"概念题 |
| 2025.09 | 单选难度抬升 · 加入更多代码追踪 |
| 2025.12 | 持续抬难度 · 表达式优先级题占比上升 |
| 2026.03 | 单选趋于稳定 · 编程题模板化 |

**整体趋势：**
1. **时事题年年有，且必考 1 题** — 2024 鸿蒙 → 2025 DeepSeek / 哪吒。
2. **代码追踪题占比逐年上升** — 从单选 5 题/卷上升到 8 题/卷。
3. **编程题难度变化不大** — 一直是 "1 个循环 + 1 个判断"。
4. **集成开发环境 / 调试**新进入考点（2024-2025）。
