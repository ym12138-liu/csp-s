### 阶段 B：一维数组（2 周，**最重要**）

**核心模板 1 · 数组定义与遍历**
```cpp
const int N = 1005;
int a[N];
int n;
cin >> n;
for (int i = 0; i < n; i++) cin >> a[i];
```

**核心模板 2 · 求和 / 求最值**
```cpp
int sum = 0, mx = -1e9, mn = 1e9;
for (int i = 0; i < n; i++) {
    sum += a[i];
    if (a[i] > mx) mx = a[i];
    if (a[i] < mn) mn = a[i];
}
```

**核心模板 3 · 满足条件的计数**
```cpp
int cnt = 0;
for (int i = 0; i < n; i++) {
    if (/* 条件，比如 a[i] % 9 == 0 && a[i] % 8 != 0 */) cnt++;
}
cout << cnt;
```

**易错点：**
- 数组下标从 **0 开始**（也可以从 1 开始统一管理，看个人习惯）
- 数组大小要够大，常见 `int a[1005]`
- 不能 `cout << a;` 打印整个数组
- 数组越界**不报错但行为不可预测**

### 阶段 C：嵌套循环（1 周）

**核心模板 1 · 九九乘法表**
```cpp
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        printf("%d*%d=%d ", j, i, i*j);
    }
    printf("\n");
}
```

**核心模板 2 · N×N 字符图形（最常考）**
```cpp
// 实心方阵
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) cout << '*';
    cout << '\n';
}

// 三角形
for (int i = 0; i < n; i++) {
    for (int j = 0; j <= i; j++) cout << '*';
    cout << '\n';
}
```

**核心模板 3 · 菱形（含偏移空格）**
```cpp
// n 必须是奇数
for (int i = 0; i < n; i++) {
    int dist = abs(i - n/2);  // 离中线的距离
    for (int j = 0; j < dist; j++) cout << ' ';     // 空格
    for (int j = 0; j < n - 2*dist; j++) cout << '*'; // 星号
    cout << '\n';
}
```

**易错点：**
- `break` 只能跳出**当前层**循环
- 字符图形题需要数清楚**每行有多少空格 + 多少星号**
- 行数和列数容易搞错

### 阶段 D：多条件判断 + 数位算法（1 周）

**第 M 位数提取（万用公式）**
```cpp
// 取 N 的从右起第 M 位（M 从 1 开始）
int digit = (N / pow10(M-1)) % 10;
// 或用循环
int x = N;
for (int i = 1; i < M; i++) x /= 10;
int digit = x % 10;
```

**漂亮数 / 自守数 / 相关数 通用判定**
```cpp
// 例：N 是 M 的"漂亮数" 当且仅当：N % M == 0 || N 含 M 这位 || 各位之和 % M == 0
bool isBeautiful(int n, int m) {
    if (n % m == 0) return true;
    int s = 0, x = n;
    while (x) {
        if (x % 10 == m) return true;
        s += x % 10;
        x /= 10;
    }
    return s % m == 0;
}
```

**斐波那契 / 阶乘**
```cpp
// 阶乘
long long fact = 1;
for (int i = 1; i <= n; i++) fact *= i;

// 斐波那契（迭代）
int a = 0, b = 1;
for (int i = 2; i <= n; i++) {
    int c = a + b;
    a = b; b = c;
}
// 第 n 项是 b
```

### 阶段 E：质数与简单算法（1 周）

**核心模板 · 试除法判素**
```cpp
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}
```

**孪生素数（间隔为 2 的素数对）**
```cpp
for (int i = 3; i <= n - 2; i++) {
    if (isPrime(i) && isPrime(i + 2)) {
        cout << i << "," << i+2 << '\n';
    }
}
```

**自守数（N² 末几位等于 N）**
```cpp
bool isAutomorph(int n) {
    long long sq = (long long)n * n;
    long long mod = 10;
    while (mod <= n) mod *= 10;
    return sq % mod == n;
}
```

### 套路 2 · 数组 + 求最值
```cpp
int n, mx = INT_MIN, mn = INT_MAX;
cin >> n;
for (int i = 0; i < n; i++) {
    int x; cin >> x;
    mx = max(mx, x);
    mn = min(mn, x);
}
cout << mx << " " << mn;
```

```cpp
int x, mx = INT_MIN;
while (cin >> x && x != -999) {
    mx = max(mx, x);

cout << mx;
```

## 5. 必背代码小卡片（**收藏 + 抄 3 遍**）

```cpp
// 1. 数组遍历 + 计数
const int N = 1005;
int a[N], n;
cin >> n;
for (int i = 0; i < n; i++) cin >> a[i];
int cnt = 0;
for (int i = 0; i < n; i++)
    if (/* 条件 */) cnt++;

// 2. 试除法判素
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}

// 3. 求位数
int digits(int n) {
    int rc = 0;
    while (n) { rc++; n /= 10; }
    return rc;
}

// 4. 求第 M 位（从右起 M=1 是个位）
int getDigit(int n, int m) {
    while (--m) n /= 10;
    return n % 10;
}

// 5. 字符图形 · 实心三角
for (int i = 0; i < n; i++) {
    for (int j = 0; j <= i; j++) cout << '*';
    cout << '\n';
}

// 6. 斐波那契第 n 项
long long fib(int n) {
    long long a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        long long c = a + b;
        a = b; b = c;
    }
    return n == 0 ? 0 : b;
}
```

## 6. 常见误区 & 提醒

| 误区 | 真相 |
|---|---|
| "数组写一次就会" | 数组下标 / 越界 / 大小要练**至少 20 道** |
| "图形输出要数空格很烦" | 用 `abs(i - n/2)` 类算偏移，比硬数空格快 |
| "多条件判断只是 if 多写几个" | **`||` 与 `&&` 优先级容易搞错**，多打括号 |
| "网络题不重要" | 二级单选 1-2 题考网络，**不练就丢 2-4 分** |
| "递归二级要不要学" | 简单递归（阶乘 / Fib）了解即可，**用迭代替代** |
| "数组开多大都行" | 开太大可能段错误，常用 1005 / 10005 |
