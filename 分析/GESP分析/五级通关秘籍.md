### 阶段 B：链表（3 周，**核心**）

**模板 1 · 单链表节点定义**
```cpp
struct Node {
    int val;
    Node* next;
};
```

**模板 2 · 头插法建链**
```cpp
Node* head = nullptr;
for (int i = 0; i < n; i++) {
    int x; cin >> x;
    Node* p = new Node{x, head};
    head = p;
}
```

**模板 3 · 尾插法建链（推荐 · 顺序与输入一致）**
```cpp
Node* head = nullptr, *tail = nullptr;
for (int i = 0; i < n; i++) {
    int x; cin >> x;
    Node* p = new Node{x, nullptr};
    if (!head) head = tail = p;
    else { tail->next = p; tail = p; }
}
```

**模板 4 · 遍历**
```cpp
for (Node* p = head; p; p = p->next) {
    cout << p->val << ' ';
}
```

**模板 5 · 删除节点（已知前驱 prev）**
```cpp
Node* del = prev->next;
prev->next = del->next;
delete del;
```

**模板 6 · 在 p 之后插入新节点**
```cpp
Node* q = new Node{val, p->next};
p->next = q;
```

**易错点（判断题常考）：**
- 链表**不支持随机访问**（要遍历 O(n)）
- 数组**插入 / 删除需要移动元素**，链表不需要
- 删除节点要**先记前驱再改 next**
- **虚拟头节点**（dummy）能让"删除头节点"和"删除其他节点"代码统一

### 阶段 C：二分查找 + 二分答案（2 周）

**模板 1 · 标准二分**
```cpp
// 在升序数组中查找 x，找到返回下标，找不到返回 -1
int bsearch(int a[], int n, int x) {
    int l = 0, r = n - 1;
    while (l <= r) {
        int mid = (l + r) >> 1;
        if (a[mid] == x) return mid;
        if (a[mid] < x) l = mid + 1;
        else r = mid - 1;
    }
    return -1;
}
```

**模板 2 · `lower_bound`（首个 >= x 的位置）**
```cpp
int lb(int a[], int n, int x) {
    int l = 0, r = n;        // [l, r) 半开区间
    while (l < r) {
        int mid = (l + r) >> 1;
        if (a[mid] < x) l = mid + 1;
        else r = mid;
    }
    return l;
}
```

**模板 3 · 二分答案（万用模板）**
```cpp
// 求满足 check(x) 的最大 x（或最小）
int lo = ?, hi = ?;
while (lo < hi) {
    int mid = (lo + hi + 1) >> 1;  // 求最大 → 上取整
    if (check(mid)) lo = mid;
    else hi = mid - 1;
}
// lo 即答案
```

**应用例（切木头）：**
```cpp
// 切木头成 K 段，每段长 ≤ x，问 x 最大可以是多少
bool check(long long x, vector<int>& a, int K) {
    long long cnt = 0;
    for (int v : a) cnt += v / x;  // 每根能切几段
    return cnt >= K;
}
```

### 阶段 D：高级排序（1.5 周）

**归并排序（必背）**
```cpp
void merge(int a[], int l, int m, int r) {
    int t[r - l + 1], k = 0, i = l, j = m + 1;
    while (i <= m && j <= r) {
        t[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    }
    while (i <= m) t[k++] = a[i++];
    while (j <= r) t[k++] = a[j++];
    for (int p = 0; p < k; p++) a[l + p] = t[p];
}

void mergeSort(int a[], int l, int r) {
    if (l >= r) return;
    int m = (l + r) >> 1;
    mergeSort(a, l, m);
    mergeSort(a, m + 1, r);
    merge(a, l, m, r);
}
// 时间复杂度 O(n log n)，稳定
```

**快速排序（必背）**
```cpp
void quickSort(int a[], int l, int r) {
    if (l >= r) return;
    int pivot = a[(l + r) >> 1];
    int i = l, j = r;
    while (i <= j) {
        while (a[i] < pivot) i++;
        while (a[j] > pivot) j--;
        if (i <= j) swap(a[i++], a[j--]);
    }
    quickSort(a, l, j);
    quickSort(a, i, r);
}
// 平均 O(n log n)，最坏 O(n²)，**不稳定**
```

**两种排序对比（必背）：**
| 维度 | 归并 | 快排 |
|---|---|---|
| 平均复杂度 | O(n log n) | O(n log n) |
| 最坏复杂度 | O(n log n) | **O(n²)** |
| 稳定性 | **稳定** | 不稳定 |
| 空间 | O(n) | O(log n) 递归栈 |
| 实际速度 | 较慢 | **较快**（常数小） |

### 阶段 E：数论（2 周，**重要**）

**欧几里得 gcd**
```cpp
int gcd(int a, int b) {
    return b ? gcd(b, a % b) : a;
}
int lcm(int a, int b) {
    return a / gcd(a, b) * b;  // 注意防溢出，先除后乘
}
```

**唯一分解定理 · 质因数分解**
```cpp
void factorize(int n) {
    for (int i = 2; (long long)i * i <= n; i++) {
        while (n % i == 0) {
            cout << i << ' ';
            n /= i;
        }
    }
    if (n > 1) cout << n;
}
```

**埃氏筛（O(n log log n)）**
```cpp
const int N = 1e6 + 5;
bool isComposite[N];
void sieveErato(int n) {
    for (int i = 2; (long long)i * i <= n; i++) {
        if (!isComposite[i]) {
            for (int j = i * i; j <= n; j += i)
                isComposite[j] = true;
        }
    }
}
// 之后 isComposite[x] == false 即 x 是素数
```

**线性筛 / 欧拉筛（O(n)）**
```cpp
int primes[N], cnt = 0;
bool isComposite[N];
void sieveLinear(int n) {
    for (int i = 2; i <= n; i++) {
        if (!isComposite[i]) primes[cnt++] = i;
        for (int j = 0; j < cnt && (long long)i * primes[j] <= n; j++) {
            isComposite[i * primes[j]] = true;
            if (i % primes[j] == 0) break;  // 关键：保证每个合数只被最小质因数筛一次
        }
    }
}
```

**口诀（判断题必考）：**
- 任何 > 1 的自然数**唯一分解**为质数乘积（**注意：质数可重复**）
- 同余 `a ≡ b (mod n)` ⇔ `(a - b) % n == 0`
- 线性筛比埃氏筛**理论上**更优（O(n) vs O(n log log n)）

### 阶段 F：贪心算法（1 周）

**贪心思想：** 每一步都选当前最优 → 期望全局最优。

**关键：** 贪心**不一定**得到全局最优解！必须先证明（或题目暗示）"局部最优 = 全局最优"。

**经典模板 · 饼干分孩子**
```cpp
// 有 n 个孩子（胃口数组 g），m 块饼干（尺寸数组 s）
// 一块饼干给一个孩子吃，要求饼干 ≥ 胃口才满意
// 求最多多少孩子满意
sort(g.begin(), g.end());
sort(s.begin(), s.end());
int i = 0, j = 0, ans = 0;
while (i < n && j < m) {
    if (s[j] >= g[i]) { ans++; i++; j++; }
    else j++;
}
```

**经典模板 · 任务调度（带截止时间 + 利润）**
```cpp
// 排序 + 优先选利润大且能赶上截止时间的任务
struct Task { int t, p; };
sort(tasks.begin(), tasks.end(), [](Task a, Task b){
    return a.p > b.p;  // 按利润降序
});
// 然后用最小堆维护时间槽
```

### 阶段 G：高精度（1 周）

**高精度加法**
```cpp
// 数组低位在前（a[0] 是个位）
vector<int> add(vector<int>& a, vector<int>& b) {
    vector<int> c;
    int carry = 0;
    for (int i = 0; i < max(a.size(), b.size()) || carry; i++) {
        int s = carry;
        if (i < a.size()) s += a[i];
        if (i < b.size()) s += b[i];
        c.push_back(s % 10);
        carry = s / 10;
    }
    return c;
}
```

**高精度减法**（同样数组低位在前）
```cpp
// 假设 a >= b
vector<int> sub(vector<int>& a, vector<int>& b) {
    vector<int> c;
    int borrow = 0;
    for (int i = 0; i < a.size(); i++) {
        int s = a[i] - borrow;
        if (i < b.size()) s -= b[i];
        if (s < 0) { s += 10; borrow = 1; }
        else borrow = 0;
        c.push_back(s);
    }
    while (c.size() > 1 && c.back() == 0) c.pop_back();  // 去前导零
    return c;
}
```

## 6. 常见误区 & 提醒

| 误区 | 真相 |
|---|---|
| "链表很简单，就是 next 指针" | **链表占编程题 ≈ 25 分**，必须练 20 道才稳 |
| "二分就是查找" | 二分**答案**才是高分项！必须练 5 道 |
| "贪心一定得最优" | 错！贪心**不保证**全局最优，是判断题陷阱 |
| "归并 = 快排" | **归并稳定 + 最坏 O(n log n) · 快排不稳定 + 最坏 O(n²)** |
| "线性筛永远比埃氏筛快" | 大数据范围下是的，**小数据**埃氏筛常数更小 |
| "高精度太烦" | **每场 1-2 题**，必须能写 |
