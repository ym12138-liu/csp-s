## 4. 6 年命题趋势观察

1. **算法稳坐 60%+ 分值**：阅读程序 + 完善程序合计 70 分，几乎全部围绕算法。
2. **二叉树 / 排列组合 = 单选必考双柱**：6 年 6 中，完全没有缺席。
3. **DP 难度逐年加深**：
   - 2022 阅读 2 鸡蛋掉落（递归 → DP 对照）
   - 2023 完善 2 编辑距离（**首个二维 DP 完善程序**）
   - 2024 阅读 2 爬楼梯最小代价（一维 DP）
4. **完善程序 = 模板背诵考场**：
   - 二分查找（21、23、24）
   - 计数排序 / 试根 / 因数枚举（19、20、22、24）
   - BFS Flood Fill（22）
   - 编辑距离 DP（23）
   - 汉诺塔（24）
5. **位运算成为新的拉分点**：21（lowbit/popcount）、22（Morton 编码）。
6. **2024 起单选侧重 C++ 语法**：const/union/类型/循环各 1 题，强调对 C++ 基础语法的扎实掌握。
7. **数学题分布稳定但形式多变**：从隔板（19/20）→ 容斥（24）→ 鸽巢（19）轮换。

## 5. "高 ROI" 必练考点 TOP 10（按累计分值×命题密度估算）

1. **二叉树性质 + 三种遍历转换**（每年都考，单选必拿 2 分）
2. **排列组合 + 隔板/捆绑/容斥**（每年都考）
3. **栈 / 队列 / 链表的基本操作**（单选 + 阅读基本盘）
4. **二分查找（标准模板 + 变体）**（完善程序高频）
5. **一维 DP 与递归→DP 改写**（爬楼梯、鸡蛋掉落）
6. **二维 DP（编辑距离 / LCS）**（2023 起进入完善程序）
7. **BFS / Flood Fill 模板**（2022 完善 2）
8. **试除法 / 因数枚举 / 质因数分解**（2020、2022、2024）
9. **贪心（区间覆盖、哈夫曼）**（2020 完善 2）
10. **位运算（lowbit / popcount / 进制转换）**（2021/2022 阅读、单选高频）
