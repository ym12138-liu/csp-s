## 0. CSP-J 初赛是在考什么？

| 维度 | 内容 |
|---|---|
| 考试结构 | 单选 15×2 + 阅读程序 3 段（约 40 分） + 完善程序 2 段（30 分） = 100 分 |
| 时间 | 120 分钟 |
| 通过线 | 一般 60 分左右进入复赛（具体每年浮动） |
| 命题语言 | C++（Pascal 已基本退出） |

**核心结论：**
- ➡️ 单选题以"概念辨识"为主：进制、二叉树、栈、链表、组合数。靠**记忆 + 简单推导**就能拿。
- ➡️ 阅读程序考"看懂经典算法"：递归、DP、BFS、字符串处理、位运算。
- ➡️ 完善程序考"写过这类模板没有"：二分、试除法、Flood Fill、计数排序、汉诺塔、编辑距离 DP。

## 2. 详细学习路径（建议 6 个月，每周 2–3 模块）

### 阶段 A：C++ 语言与基础数据结构（4 周）

**学习目标：** 看到任意 30 行以内的 C++ 程序能正确读懂输出。

**具体内容：**
1. **C++ 基本语法**：`int / long long / char / float / double / bool` 的范围与字节数；`for / while / do-while` 循环；`if-else`；函数；引用与指针的区别；`const`、`struct`、`union`。
2. **数组与字符串**：`int a[N]`；`std::string`、`s.size()`、`s[i]`、`s + s`、`s.find()`、`std::reverse`。
3. **STL 入门**：`vector<int>`、`pair<int,int>`、`sort()`。
4. **手写基础数据结构**：栈（`std::stack` 和数组实现两种）、队列（`std::queue`）、单链表（指针实现）。

**代码模板：手写栈**
```cpp
const int N = 1e5+5;
int stk[N], top = 0;
void push(int x) { stk[++top] = x; }
void pop()       { --top; }
int  topv()      { return stk[top]; }
bool empty()     { return top == 0; }
```

**练习：** 洛谷 P1739（表达式括号匹配）、P1996（约瑟夫问题）。

### 阶段 B：经典模板算法（6 周，最重要）

#### B1. 排序（1 周）
- **必背：** 冒泡、选择、插入（手写）；归并、快排（理解原理）。
- **使用：** `sort(a, a + n)`、`sort(a, a + n, greater<int>())`。
- **稳定性：** 冒泡、插入、归并、计数 = 稳定；选择、快排、堆排 = 不稳定。

#### B2. 二分查找（4 天）
模板必须刻进肌肉记忆：
```cpp
// 在升序数组中查找第一个 >= x 的位置
int lower_bound_my(int* a, int n, int x) {
    int l = 0, r = n;            // [l, r) 半开区间
    while (l < r) {
        int mid = (l + r) >> 1;
        if (a[mid] < x) l = mid + 1;
        else r = mid;
    }
    return l;
}
```
**变体：** 二分答案（猜数字）、二分缺失元素（CSP-J 2023 完善 1）。

#### B3. 递归（4 天）
**经典 3 道：**
- 阶乘 / 斐波那契
- 汉诺塔（CSP-J 2024 完善 2）
- 全排列 / 子集

**口诀：** 写递归先写"边界条件"，再写"递归步骤"。

#### B4. 枚举与试除（3 天）
```cpp
// 质因数分解（CSP-J 2020 完善 1）
int n;
for (int i = 2; (long long)i * i <= n; ++i) {
    while (n % i == 0) {
        cout << i << ' ';
        n /= i;
    }
}
if (n > 1) cout << n;
```

```cpp
// 枚举正因数（CSP-J 2022 完善 1）
for (int i = 1; (long long)i * i <= n; ++i)
    if (n % i == 0) {
        cout << i << ' ';
        if (i != n / i) cout << n / i << ' ';
    }
```

#### B5. DFS / BFS（1 周）
**DFS 模板（回溯）：**
```cpp
void dfs(int dep) {
    if (dep == n) { /* 处理结果 */ return; }
    for (int i = 0; i < choices; ++i) {
        if (vis[i]) continue;
        vis[i] = true; path[dep] = i;
        dfs(dep + 1);
        vis[i] = false;
    }
}
```

**BFS 模板（Flood Fill，CSP-J 2022 完善 2）：**
```cpp
int dx[4] = {0, 0, 1, -1};
int dy[4] = {1, -1, 0, 0};

void bfs(int sx, int sy) {
    queue<pair<int,int>> q;
    q.push({sx, sy});
    int color = grid[sx][sy];
    grid[sx][sy] = NEW_COLOR;
    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();
        for (int d = 0; d < 4; ++d) {
            int nx = x + dx[d], ny = y + dy[d];
            if (nx < 0 || nx >= R || ny < 0 || ny >= C) continue;
            if (grid[nx][ny] != color) continue;
            grid[nx][ny] = NEW_COLOR;
            q.push({nx, ny});
        }
    }
}
```

#### B6. 动态规划（2 周，最重要的算法之一）

##### 一维 DP — 爬楼梯最小代价（CSP-J 2024 阅读 2）
```cpp
// dp[i] = 到达第 i 阶的最小代价
dp[0] = 0; dp[1] = cost[0];
for (int i = 2; i <= n; ++i)
    dp[i] = min(dp[i-1], dp[i-2]) + cost[i-1];
```

##### 二维 DP — 编辑距离（CSP-J 2023 完善 2）
```cpp
// dp[i][j] = s1[0..i] → s2[0..j] 的最少操作数
for (int i = 0; i <= m; ++i) dp[i][0] = i;
for (int j = 0; j <= n; ++j) dp[0][j] = j;
for (int i = 1; i <= m; ++i)
    for (int j = 1; j <= n; ++j) {
        if (s1[i-1] == s2[j-1])
            dp[i][j] = dp[i-1][j-1];
        else
            dp[i][j] = 1 + min({dp[i-1][j], dp[i][j-1], dp[i-1][j-1]});
    }
```

##### 必练 DP 题型
- 最长上升子序列（LIS） O(n²) 入门版
- 0-1 背包入门
- 鸡蛋掉落（CSP-J 2022 阅读 2）
- 编辑距离 / LCS

### 阶段 C：数学与离散数学（3 周）

#### C1. 排列组合（必考！）
- **A(n,k) = n!/(n-k)!**：排列数
- **C(n,k) = n!/(k!(n-k)!)**：组合数
- **隔板法**：n 个相同球分到 k 个不同盒子，每盒至少 1 个 → C(n-1, k-1)（CSP-J 2020 题 14）
- **捆绑法**：相邻元素先看作整体（CSP-J 2024 题 14）
- **容斥**：|A∪B∪C| = ∑|A| - ∑|A∩B| + |A∩B∩C|（CSP-J 2024 题 3）
- **错排**：D(n) = (n-1)(D(n-1) + D(n-2))

#### C2. 数论
```cpp
// 欧几里得求 GCD
int gcd(int a, int b) { return b ? gcd(b, a % b) : a; }

// 素数判断（试除法 + √n 优化）
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; (long long)i * i <= n; ++i)
        if (n % i == 0) return false;
    return true;
}
```

#### C3. 鸽巢原理 / 抽屉
"n+1 个物体放入 n 个抽屉，必有一个抽屉至少放 2 个物体"（CSP-J 2019 题 12）。

### 阶段 D：数据结构进阶（2 周）

#### D1. 二叉树（必考！）
- **完全二叉树性质**：n 节点完全树高度 = ⌊log₂ n⌋ + 1
- **数组存储**：根 = 1，节点 i 的左子 = 2i，右子 = 2i+1，父节点 = ⌊i/2⌋
- **三种遍历**：前序（根左右）、中序（左根右）、后序（左右根）
- **重要题型**：
  - 前+中→后（CSP-J 2024 题 12）
  - 后+中→前（CSP-J 2019 题 14）
  - 前+中→后（CSP-J 2023 题 11）

**记忆口诀：** 中序"找根分左右"，前序/后序"先认根"。

#### D2. 表达式求值
- 中缀 → 后缀（用栈）
- 后缀计算（用栈）
- 中缀 → 前缀（先反转，后缀法，再反转）

#### D3. 链表
- 单链表：头插 / 尾插 / 删除（注意 `prev->next` 与 `cur` 的指针更新顺序）
- 双向循环链表：插入需要 4 个指针操作（CSP-J 2022 题 11）

#### D4. 图论基础
- **握手定理**：所有顶点度数之和 = 边数 × 2（CSP-J 2024 题 11）
- **n 顶点连通图至少 n-1 条边**（即树）
- **拓扑排序**：DAG 的合法序列（CSP-J 2023 题 12）

## 4. 常见误区与避坑

| 误区 | 真相 |
|---|---|
| "我会写题就行，单选不重要" | 单选 30 分占 30%，**是最容易拿满的部分**，不能丢 |
| "完善程序太难，靠蒙" | 完善程序 30 分，蒙对率仅 25%，**练 12 段真题就能稳拿 20+** |
| "DP 是提高组才考的" | CSP-J 2022/2023/2024 连续 3 年都考了 DP（一维 + 二维都有） |
| "二叉树性质题考过了不会再考" | **6 年 6 中**，是最稳定的考点 |
| "C++ 语法不重要，会写算法就行" | CSP-J 2024 单选 4 题考语法（int 范围、struct、循环、char） |
| "数学题靠题感" | 隔板/捆绑/容斥**都有套路**，背公式 + 练 5 道就够 |
