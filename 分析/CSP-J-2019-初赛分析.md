## 四、本年度考点频次小结

| 知识一级 | 题数/段 | 估算分值 |
|---|---|---|
| 计算机基础（域名 / 二进制 / 奖项） | 3 题 | 6 |
| 程序语言（int / 循环等价） | 2 题 | 4 |
| 数据结构（链表 / 二叉树 / 数组维护） | 3 题 + 阅读 2 部分 | ≈ 12 |
| 算法（折半 / 贪心 / 字符串 / 分治 / 递归 / 计数排序） | 2 题 + 阅读 1+3 + 完善 1+2 | ≈ 60 |
| 数学（组合 / GCD / 素数 / 鸽巢 / 对称计数） | 5 题 | 10 |

**命题特点：**
- **数学题占比全卷最高（10/30 单选分）**，鸽巢/GCD/素数/对称计数齐上。
- 阅读 3 是分治深度递归题，难度对 CSP-J 而言偏高。
- 完善程序 2 计数排序是 CSP-J 罕见的高级排序考点。
