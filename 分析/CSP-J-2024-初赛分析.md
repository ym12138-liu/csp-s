## 四、本年度考点频次小结

| 知识一级 | 题数/段 | 估算分值 |
|---|---|---|
| 计算机基础（进制 / 存储 / 格雷码 / OS / 编译器） | 5 题 | 10 |
| 程序语言（int / 类型 / 循环 / char） | 4 题 | 8 |
| 数据结构（图度数 / 二叉树 / 栈） | 3 题 | 6 |
| 算法（二分 / 试除 / DP / 递归 / 汉诺塔） | 1 题 + 阅读 1+2+3 + 完善 1+2 | ≈ 70 |
| 数学（组合容斥 / 捆绑） | 2 题 + 完善 1 部分 | ≈ 6 |

**命题特点：**
- 程序语言基础题占比异常高（4 题/8 分），强调 C++ 基本语法掌握度。
- 阅读 + 完善全部使用"教学型"经典模板（试除素数 / 爬楼梯 DP / 汉诺塔），难度回到温和水平。
- 多进制混合运算（题 2）题型新颖，对进制的熟练程度要求高。
