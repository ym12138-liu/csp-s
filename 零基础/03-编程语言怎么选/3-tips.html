这 3 件事
是误传

!
"直接学 C++ 最高效 · 跳过 Scratch"
小学低年级直接 C++ 大概率挂掉 · 语法严 · 错误提示晦涩 · 没逻辑基础先打地基
!
"学 Python 没用 · 比赛不让用"
Python 能做更多实用项目(爬虫 / AI / 数据) · 不冲信奥的娃学 Python 比 C++ 更有持续动力
!
"Scratch 太简单 · 浪费时间"
Scratch 练的是逻辑思维不是语法 · 跳过它直接打字写代码 · 很多娃 3 个月就放弃了

语言只是工具 · 思维才是目的

不被忽悠 · 选对路
