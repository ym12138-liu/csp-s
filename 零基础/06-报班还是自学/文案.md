家长群里这事儿吵翻了,
其实根本没有"报班好"或"自学好"的标准答案,
看孩子。

报班和自学的真实对比:
报班 有体系 / 老师纠错 / 同学一起学有动力 / 大连均价 2-5 万一年 / 但容易"过度包装"。
自学 免费 / 灵活 / 家长 / 娃要有自驱力 / 资源 OI Wiki + 洛谷 / 缺点 = 遇坑没人答。

3 种娃 3 种选法:
主动型娃 → 自学就行,给资源就能上手。
需要陪伴型 → 报班,老师同伴提供环境。
冲信奥型 → 报班 + 自学都要,单一不够。

4 句话听到就要警惕:
"现在不报班、以后追不上" → 编程不是奥数,不存在"窗口期",初一开始的娃也能拿 NOIP。
"我们是 NOI 教练带、直通省队" → 省队是顶级娃自带光环,教练只是辅助,同样老师 90% 娃也进不了省队。
"GESP 八级保过、不过退费" → "包过班"通常 = 大量刷题 + 走捷径,过了八级 ≠ 真有能力,CSP-S 直接破防。
"报全年课、一站到底" → 先试听 + 报短期,看效果再续,大连家长教训:一报全年容易后悔。

试听 + 短期 + 看娃反应 = 不踩坑。

报班 4 步走避坑:
第 1 步 试听 1-2 节,免费体验 / 看老师讲不讲思路、不是死灌代码。
第 2 步 先报 3 个月短期,看娃主动写代码了吗 / 抗拒作业 = 放弃。
第 3 步 看作业反馈,老师一周内逐题点评吗 / 没反馈就是水课。
第 4 步 3 个月再决定,有效果 → 续报半年、没效果 → 立即停 / 转自学 + OI Wiki。

家长省钱秘诀:短期试 / 长期续 / 没效果立刻停。
别一次买全年,退费比报名难 10 倍。
