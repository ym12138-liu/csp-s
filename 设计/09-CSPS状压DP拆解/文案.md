看到 n ≤ 20 直接条件反射状压,这是 CSP-S 卷王的基本功

状压 DP 是 CSP-S 难度天花板里最像"通关密码"的那块。
看到 n ≤ 20 就该条件反射,几乎是套路题。
2020 / 2024 各出过一道硬核拆解,套路完全一样。

什么时候用状压?
n ≤ 20 这个上限是判断标志,
状态可以表示成 选 / 没选 的 0/1 组合,
把"集合"压成一个二进制数 s,第 i 位为 1 表示选了 i。

状态怎么定义?
f[s][i] = 已经走过集合 s 中所有点、当前停在 i 时的最优值。
边界 f[1<<0][0] = 0,
答案 f[(1<<n)-1][end]。

转移怎么写?
枚举上一个位置 j,j 必须已经在集合 s 里,
从 s 去掉 i 是 s ^ (1<<i),
从 j 转移到 i: f[s][i] = max(f[s^(1<<i)][j] + cost[j][i]),写出来就这一行。

TSP 标准模板长这样:
for (int s = 0; s < (1<<n); ++s)
  for (int i = 0; i < n; ++i) if (s>>i & 1)
    for (int j = 0; j < n; ++j) if (s>>j & 1)
      f[s][i] = min(f[s][i], f[s^(1<<i)][j] + cost[j][i]);
