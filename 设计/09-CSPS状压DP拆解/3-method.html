METHOD · 状压三步

看到 n ≤ 20
就条件反射状压

1

什么时候用状压

n ≤ 20 · 状态可以表示成选/没选的 0/1 组合
把"集合"压成一个二进制数 s · 第 i 位为 1 表示选了 i

2

状态怎么定义

f[s][i] = 已经走过集合 s 中所有点 · 当前停在 i 时的最优值
边界：f[1<<0][0] = 0 · 答案：f[(1<<n)-1][end]

3

转移怎么写

枚举上一个位置 j · j 必须已经在集合 s 里
从 s 去掉 i：s ^ (1<<i)
从 j 转移到 i：f[s][i] = max(f[s^(1<<i)][j] + cost[j][i])

TSP 标准模板 
for (int s = 0; s < (1<<n); ++s)
    for (int i = 0; i < n; ++i) if (s>>i & 1)
        for (int j = 0; j < n; ++j) if (s>>j & 1)
            f[s][i] = min(f[s][i], f[s^(1<<i)][j] + cost[j][i]);
