状压
三步法

1

什么时候用状压

n ≤ 20 时就该想 · 状态可表示成 选/没选 0/1 组合 · 把"集合"压成二进制数 s

2

状态怎么定义

f[s][i] = 已经走过集合 s · 当前停在 i 时的最优值
边界 f[1<<0][0] = 0 · 答案 f[(1<<n)-1][end]

3

转移怎么写

枚举上个位置 j · j 必须已经在集合 s 里
从 s 去掉 i 是 s ^ (1<<i)

TSP 标准模板 
for (int s = 0; s < (1<<n); ++s)
  for (int i = 0; i < n; ++i) if (s>>i & 1)
    for (int j = 0; j < n; ++j) if (s>>j & 1)
      f[s][i] = min(f[s][i], f[s^(1<<i)][j] + cost[j][i]);
★ 一句话 ★
"状态空间 ≤ 2²⁰" · 这就是状压的应用边界
