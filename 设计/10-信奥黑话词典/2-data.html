{ DICT } 12 个黑话

家长扫盲卡
收藏不亏

DP
Dynamic Programming
把问题拆成 子问题 · 把子问题答案存起来
DFS
Depth-First Search
递归 一条道走到黑 · 然后回头
BFS
Breadth-First Search
用队列 · 一圈一圈 向外扩
KMP
字符串匹配
用 next 数组 跳过失败位置
Trie
前缀树
每个节点存一个字母 · 查前缀超快
LCA
最近公共祖先
树上两个节点 共同的祖先 中最深的那个
MST
最小生成树
连通所有点 · 边权和最小 的方案
LIS
最长上升子序列
数组里 选一些保持递增 最多能选几个
LCS
最长公共子序列
两串里 最长的相同片段（可不连续）
DSU
并查集
快速判断 两个东西是不是一伙的
RMQ
区间最值查询
问 区间内最大/最小 用 ST 表 O(1) 答
MITM
折半搜索
2ⁿ 跑不动 · 分两半各跑 2^(n/2)
{ Tip } 这 12 词覆盖 CSP-J/S 80% 的算法术语
