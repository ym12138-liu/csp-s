认出来就能直接套思路、不认识就硬看代码,效率差 5 倍。

按年份大致分这几类:
2019 字符大小写按因数翻转 / 分治深度递归求带权和
2020 替换密码 CSP 编码表 / k 进制递增计数器
2021 popcount + lowbit / 欧拉筛 + 因子函数
2022 Morton 编码 (位交错) / 鸡蛋掉落递归 vs DP
2023 LCS 判断字符串循环移位
2024 爬楼梯最小代价 DP
2025 排序 + 双指针 1D DP / LCS 二维 DP

近 4 年 DP 出现 5 次,这是最关键的趋势。不学 DP 阅读直接送 14 分。

识别套路其实就 3 招:
看到 dp[i] = max/min(dp[i-1], ...),二维就是 dp[i][j],
关键词出现"状态/转移/边界",多半就是爬楼梯、LCS、编辑距离这一类。
看到函数调用自己 + if (n==0) return 这种边界,
看是不是 solve(left) + solve(right) 这种二分模式,二分 = 分治。
遇到 str[i] - 'A'、isdigit、str.size() 几乎确定是字符串题,Base64 / RLE 都属于这一类变体。

先扫"算法骨架",再去抠每一行实现,做题速度能翻倍。
