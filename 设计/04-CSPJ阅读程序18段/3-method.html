DP

识别 DP

看到 dp[i] = max/min(dp[i-1], ...) · 二维就是 dp[i][j]。

关键词：状态 / 转移 / 边界。多半是爬楼梯 / LCS / 编辑距离一类。

REC

识别递归 / 分治

函数调用自己 · 有 if (n==0) return ... 的边界条件。

看是不是 solve(left) + solve(right) 这种二分模式 = 分治。

STR

识别字符串处理

遇到 str[i] - 'A'、isdigit、str.size() 几乎确定。

注意：Base64 / RLE / 字符映射都是这一类的变体。
