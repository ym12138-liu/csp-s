DP 识别

看到状态转移就是 DP

dp[i] = max/min(dp[i-1], ...) · 二维就是 dp[i][j]

关键词:状态 / 转移 / 边界 · 多半是爬楼梯 / LCS / 编辑距离

REC 识别递归 / 分治

函数调用自己 = 递归

if (n==0) return ... · return solve(left) + solve(right)

看是不是二分模式 · 是的就是分治

STR 识别字符串处理

遇到 ASCII 算术几乎确定

str[i] - 'A' · isdigit · str.size()

注意:Base64 / RLE / 字符映射 都是这一类的变体
