四级是真正意义上的算法关,
三级孩子上来摸不到指针、不会写排序,大概率会先卡两周。
这是普遍现象,别慌。

三级 vs 四级关键差异:
三级仅基本类型 + 数组 / 仅一维数组 / 仅 C++ 内置函数 / 不考排序算法 / 不考复杂度分析。
四级新增指针 + 引用 / 新增二维数组 / 必考自定义函数 / 三种排序必考 / 复杂度 O(n) / O(n²)。

新增 5 项必补:
1. 指针 (*p / &x / 指针运算) ≈ 48 分
2. 函数 (形参实参 / 引用传递) ≈ 50 分
3. 三种排序 (冒泡 / 选择 / 插入) ≈ 50 分
4. 二维数组 + 结构体 ≈ 60 分
5. 时间复杂度 (O(n²) 等) ≈ 14 分

指针有 3 个最基本的写法,3 个搞懂了基本就过了:
int x = 10;
int* p = &x; // p 取地址
cout << *p; // 解引用 = 10
*p = 20; // 修改 → x 也变 20
关键 · * 解引用 / & 取地址 · 大小固定 8 字节。

引用传递最常用的是 swap:
void swap(int& a, int& b) { int t=a; a=b; b=t; }
关键就一个字"&",写不写 & 决定能不能改原变量。
