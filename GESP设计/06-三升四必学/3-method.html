1 · 指针基本三连 
int x = 10;
int* p = &x;        // 取地址
cout << *p;            // 解引用 = 10
*p = 20;              // 修改 → x 也变 20
关键 · * 解引用 / & 取地址 · 大小固定 8 字节
2 · 引用传递交换 
void swap(int& a, int& b) {
    int t = a; a = b; b = t;
}
// 调用 swap(x, y) 后 x 和 y 真的交换
关键 · 加 & 才会修改原变量
3 · 三种排序 
// 冒泡（稳定 · O(n²)）
for (int i = 0; i < n-1; i++)
    for (int j = 0; j < n-1-i; j++)
        if (a[j] > a[j+1]) swap(a[j], a[j+1]);

// 选择（不稳 · O(n²)）
for (int i = 0; i < n-1; i++) {
    int mn = i;
    for (int j = i+1; j < n; j++)
        if (a[j] < a[mn]) mn = j;
    swap(a[i], a[mn]);
}
关键 · 稳:冒泡/插入 · 不稳:选择/快排
