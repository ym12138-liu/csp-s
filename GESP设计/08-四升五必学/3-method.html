2 · 二分查找 
int bs(int a[], int n, int x) {
    int l=0, r=n-1;
    while (l <= r) {
        int m = (l+r) >> 1;
        if (a[m] == x) return m;
        if (a[m] < x) l=m+1; else r=m-1;
    }
    return -1;
}
关键 · 必须有序 · 找到返回下标
3 · 欧几里得 gcd 
int gcd(int a, int b) {
    return b ? gcd(b, a%b) : a;
}
int lcm(int a, int b) {
    return a / gcd(a,b) * b;  // 先除后乘防溢出
}
关键 · 1 行递归 + lcm 先除后乘
4 · 埃氏筛素数 
bool comp[N];
for (int i=2; (long long)i*i <= n; i++)
    if (!comp[i])
        for (int j=i*i; j<=n; j+=i)
            comp[j] = true;
// comp[x] == false 即 x 是素数
关键 · 从 i*i 开始筛 · 复杂度 O(n log log n)
