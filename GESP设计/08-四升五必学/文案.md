四级到五级,链表 + 数论上来了,接近 CSP-J 入门难度

四级到五级跨度也不小,主要是链表第一次登场,
这玩意没碰过的孩子上来一脸懵,熬一两周就好了。

四级 vs 五级关键差异:
四级仅数组 + 结构体 / 三种 O(n²) 排序 / 顺序查找 / 仅简单递归 / 不考数论。
五级新增链表 (单/双/循环) / 归并 + 快排 O(n log n) / 二分查找 + 二分答案 / 新增贪心 + 分治 / gcd / 素数筛 / 分解。

5 项必补:
1. 链表 (单/双/循环 + 增删) ≈ 100 分
2. 归并 + 快排 O(n log n) ≈ 54 分
3. 二分查找 + 二分答案 ≈ 60 分
4. 数论 (gcd / 素数筛 / 分解) ≈ 90 分
5. 贪心 + 分治 + 高精度 ≈ 50 分

链表头插法手敲一遍就懂了:
struct Node { int v; Node* next; };
Node* head = nullptr;
for (int i=0; i<n; i++) {
  int x; cin>>x;
  head = new Node{x, head};
}
关键 · 头插法顺序与输入相反,手敲 10 遍即可。

二分查找一定要必须有序,
找到返回下标,找不到返回 -1。
