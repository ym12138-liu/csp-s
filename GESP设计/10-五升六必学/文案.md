5 项必补:
1. 二叉树 (三种遍历 + 推导) ≈ 100 分
2. 二叉搜索树 BST (插入 / 查找 / 验证) ≈ 60 分

5. DFS / BFS + 哈夫曼编码 ≈ 90 分

二叉树三种遍历模板必须默到肌肉记忆:
struct TN { int v; TN *l, *r; };
void pre(TN* p) { if(!p) return; cout<<p->v; pre(p->l); pre(p->r); }
void in(TN* p)  { if(!p) return; in(p->l);  cout<<p->v; in(p->r); }
void post(TN* p){ if(!p) return; post(p->l); post(p->r); cout<<p->v; }
关键就一句话——"中序找根分左右"。

BST 插入也很短:
TN* insert(TN* r, int x) {
  if (!r) return new TN(x, nullptr, nullptr);
  if (x < r->v) r->l = insert(r->l, x);
  else if (x > r->v) r->r = insert(r->r, x);
  return r;
}
关键 · 左小右大、中序遍历升序。
