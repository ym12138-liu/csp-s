GESP 一级到二级,差距就这 3 块,补不上就是 50 分掉

一升二是第一个分水岭,很多孩子拿过一级就觉得"会编程了",
碰到二级真题直接懵。
对比一下两级的差异就清楚:

一级仅基本类型变量、单层 for / while、简单 if 单条件、仅 char 字符、仅时事 + 历史。
二级新增一维数组、新增嵌套循环、多条件判断、新增字符串遍历、新增网络 + 存储。

新增的 5 块就是 50 分差距,缺一不可。

第一项 一维数组(定义 / 遍历 / 求最值)≈ 60 分
掌握 int a[1005],会遍历、求和、求最值,做 20 道数组题。

第二项 嵌套循环(双层 for / 图形输出)≈ 50 分
九九乘法表 + 三角形 + 菱形,5 个图形手敲,
N×N 字符图形必考。

第三项 多条件判断(漂亮数 / 自守数)≈ 60 分
漂亮数和自守数判定,各 5 题。

第四项 字符与 ASCII('A'+1 等)≈ 14 分
'A'+1 字母转换 + 背 IPv4 / TCP / MB 这种送分题不丢。

第五项 网络(IPv4 / TCP / 存储单位)≈ 10 分
这块就是背,1 周搞定。

6 周补差路线给大家:
W1-2 数组入门,掌握 int a[1005],遍历、求和、求最值,做 20 道。
W3 嵌套循环,九九乘法表 + 图形 5 个,各 5 题。
W4 多条件 + 数位,漂亮数 / 自守数 / 求位数 / 第 M 位,各 5 题。
W5 限时刷 2025 真题,3 套二级真题 90 分钟一套,找最弱模块。
W6 限时刷 2025 + 模考,2025 + 2026.03 真题,稳定 70+ 才进三级。

数组 + 嵌套循环 = 二级 60+。大连娃普遍 6 周冲过线。
