3 · 多条件 · 漂亮数判定 
bool /*pretty*/(int n, int m) {
    if (n % m == 0) return true;
    int s = 0, x = n;
    while (x) {
        if (x % 10 == m) return true;
        s += x % 10;
        x /= 10;
    }
    return s % m == 0;
}
关键 · 三个条件 任一满足即为漂亮数
