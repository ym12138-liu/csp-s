六级 vs 七级关键差异:

5 项必补:

2. 哈希表 (链地址 / 线性探测) ≈ 60 分

4. 复杂度递推式 (主定理) ≈ 50 分
5. 强连通 / 生成树概念 ≈ 30 分

图论邻接表 + BFS 模板必背:
vector<int> adj[N];
queue<int> q; bool vis[N];
q.push(s); vis[s]=true;
while (!q.empty()) {
  int u = q.front(); q.pop();
  for (int v : adj[u])
    if (!vis[v]) { vis[v]=true; q.push(v); }
}
关键 · BFS 用队列 + 访问数组、避免重复访问。

哈希表链地址法:
vector<int> ht[P];
void insert(int x) { ht[x % P].push_back(x); }
关键 · P 必取素数,防规律输入冲突。
