四大图算法每个都有套模板,死磕练熟即可。
Kruskal 最小生成树:
sort(edges.begin(), edges.end(), cmp);
int sum = 0, cnt = 0;
for (auto& e : edges) {
  int fu=find(e.u), fv=find(e.v);
  if (fu == fv) continue;
  fa[fu] = fv; sum += e.w;
  if (++cnt == n - 1) break;
}
关键 · 排序边 + 并查集 · O(m log m)。

Dijkstra 堆优化:
priority_queue<pii, vector<pii>, greater<>> pq;
pq.push({0, s}); d[s] = 0;
while (!pq.empty()) {
  auto [dv, u] = pq.top(); pq.pop();
  if (dv > d[u]) continue;
  for (auto [v,w] : adj[u])
    if (d[u]+w < d[v]) {
      d[v] = d[u]+w;
      pq.push({d[v], v});
    }
}
关键 · 不能处理负权 · O((n+m) log n)。

Floyd 多源最短路 3 行就够:
for (int k=1; k<=n; k++)
  for (int i=1; i<=n; i++)
    for (int j=1; j<=n; j++)
      d[i][j] = min(d[i][j], d[i][k]+d[k][j]);
关键 · k 必须最外层 · O(n³) 全源。
